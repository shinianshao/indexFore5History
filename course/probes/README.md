# course/probes/ —— 系统体检与隐患探针工具箱

本目录用于存放课程中由学员编写并运行的 7 大系统体检探测脚本：

1. `audit_01_corpus_size.py`：阶段一·微信小程序包体积与内存极限压测探针
2. `audit_02_dist_sync.py`：阶段一·双轨同构构建漂移与资产一致性比对探针
3. `audit_03_excel_sanity.py`：阶段二·Excel 权威源格式损坏与静默污染体检探针
4. `audit_04_false_positive.py`：阶段三·文言否定句、转述引用与派遣假行迹排查探针
5. `audit_05_place_ambiguity.py`：阶段四·历史同名异地与地名沿革时空折线跳跃体检探针
6. `audit_06_relations_graph.py`：阶段五·人物关系网络孤立点、断头边与失效证据体检探针
7. `audit_07_frontend_fps.py`：阶段四·万级行迹与力导向节点渲染帧率压测探针
