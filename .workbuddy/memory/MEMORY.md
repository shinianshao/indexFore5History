### 是什么
离线管线 + 本地网页的**古籍实体索引**（非全文检索）。五书 564 篇 / 223,164 句 / 49,069 段 / 2,402 人（67,849 极致纯净命中）/ 1,621 地名（119,077 命中）。
`app/`（FastAPI 8800）日常 · `dist/` 离线快照（**不在 git**）· `web/` 冻结待删。
`app/` 与 `pipeline/` **刻意不互相 import** → 常量抄两份就必须有断言对账。

## 三红线
1. **单向数据流**：`workbook/*.xlsx` 只能人写，pipeline 只读 → 要写就「新版本 + 报差异」。
2. **句子主键 uid** `md5(篇|段序|句序)[:12]`（**不含原文**）；拆→前半继承，并→merged，删→dead **不物理删**。⚠️ 实现共五处，改一处改五处。
3. **规则进代码，数据进表格**。

## 环境（会制造假失败，先记住）
- **python 必须用系统 3.12.10**（托管 3.13.12 没 opencc → `check_trad.py` 假红）。
- **本机 Python 新建/删除一律 `PermissionError WinError 5`**（bash 的 `cp`/`mv` 正常）→ `tempfile` 不可用（用 `pipeline/_scratch/_run_with_tmp.py` 包一层）、`openpyxl.save()` 会**先截断目标再失败**留下坏 xlsx → **严禁用裸 `wb.save`，统一走 `common.safe_save_workbook` 原子替换**。
- 回归 `bash scripts/run_all.sh`（~280s，含 UI）；**重建前必须停 8800**。`curl` 加 `--noproxy '*'`。
- `verify_p3` 全跑 4–5 分钟 → **长断言必须配快速版**（`verify_p3_mark.py` / `_overrides.py` / `_place.py` / `verify_p3_paras.py`）。

## ⚠️ 最贵的三类坑
- **`s`/`e` 是 Python Unicode 码位下标**，前端既不能 `indexOf`（8,319 条错）也不能裸 `slice`（非 BMP 新造 63 条错）→ 只能走 `hitSpan` 三级回退。
- **「是否生效」不在数据里，只能算**；**前端读回 xlsx 的值必须先归一**（`17.0` vs `17` → 徽章静默消失）。
- **xlsx sheet/列名要自动探测**（`_pick_sheet`）：表叫 `人物`、列 `dynasty`、主键 `id`。
- **段落与句子完整性**：历史丢句 56.8% 已修复为全量 223,164 句；纯注文空段落靠 `last_text_pseq` 锚定正文段；`chapter_sentences` 默认 `limit` 提升至 5000。

## 断言铁律
每修一个坑加一条断言，基线**只许升不许降**；改完必须「**注入 → 变红 → 还原 → 变绿**」（审查脚本 `verify_p1_fault_injection.py` 5/5 闭环、`verify_places_enrichment.py` 10/10 闭环、`verify_persons_enrichment.py` 10/10 闭环）。
**断在「会被打破的那一层」**，端点层**必须真打一次 HTTP**。
⚠️ **恒真断言已踩七种**（空列表 `all()`、宽松选择器、`ms[i]` 不求值、断终态、断「拼回原句」、`len(t)==len(list(t))`、**验了引擎没验接线**）→ 每条都要问「样本为空时它是什么结果」；抽产品码自测**必须再配静态检查守呼叫点**。
⚠️ **审查报告给的「建议改法」本身可能是错的**，每条自己实测再动手。⚠️ 注入脚本：备份只做一次 + 注入前 assert 锚点 + 注入后重跑导出。
⚠️ **改了 UI 形状旧断言会红** = 断言过期不是 bug，升级它别删。

## UI / 测试
写错时症状是「**等不到**」不是报错。等待条件必须是**这一屏独有**的东西 + 先 `out.innerHTML=""` 清屏。
`waitFor` 返回布尔不是元素；`location.hash` set同值不触发；真点「写入」会脏权威源 → 沙盒 `BOOKINDEX_OVERRIDES`；**后台服务必须 `run_in_background: true`**（用 `&` 会被回收 → 大面积 0 条，先怀疑服务死了）。**前端文案一律繁体**。

## 联机 / 离线一致性
`dist/app.js` 是 `app/web/app.js` 的拷贝，**永不复制第三份前端**。
⚠️ `export_static.py` 的 `--check`/`--verify` **只验不写** → **真导出必须不带参数**。
⚠️ **响应体组装必须放 db 层**（端点与导出共用）；**「按书作用域变化」的数字一律前端算**（离线路由忽略查询串）；**常量漂移是同一类坏**（`ALIAS_KINDS`/`BOOKS[].era`/`ERA_NAMES`）。
