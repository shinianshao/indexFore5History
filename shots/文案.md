## 版本 A · 通用（发朋友圈 / 群里）

折腾了几天，做了个小东西：**《史记》全文检索器**，纯本地跑，不联网、不上传。

130 篇、69 万字全部入库，人物 388 位、地名 281 个。输入一个人名或地名，它把
130 篇自动分成两类——「整篇讲 TA 的传记」和「其他篇目顺带提到」，每处都摊开
原文，并把书里**真正写的那个称呼**高亮出来。

最能说明问题的是搜「刘邦」：《史记》里「刘邦」这两个字**一次都没出现过**，全书
写的是 **漢王**（353 处）、**高祖**（302）、**沛公**（242）、**劉季**（15）。
这个工具照样一处不落——58 篇 735 处顺带提及，再加一篇整篇讲他的《高祖本纪》。

同名不同人也做了上下文消歧：《淮南衡山列传》里 19 处「厲王」，其实都是淮南厉王
**刘长**，不是周厉王。

还能点「讀全篇」直接读原文，正文里凡是他/她的称呼全部高亮，一眼看清哪句在讲谁。

## 版本 C · 给懂技术的朋友

手搓了一个《史记》实体索引：130 篇 / 69 万字 / 388 人 / 281 地。

难点根本不在全文搜索，在**别名归一 + 同名消歧**——古书里「刘邦」这个写法压根
不存在，得先把 漢王 / 高祖 / 沛公 / 劉季 归到同一个实体；而「厲王」在同一本书里
既是周厉王、又是淮南厉王刘长，只能靠上下文判。

离线管线一整套：
切句 → 建人物词典 → 别名标注 → **七级上下文消歧**（owner/chapter/paragraph/era/
sentence/related/guess）→ 泛称**定点迭代回灌**（同一称号不能自证、不同称号可互证）
→ 地名**四道闸门**（人名占用区间 / 邻字守卫 / 裸匹配禁用 / 人名审读表）→
**繁简·异体三层字面层守卫**（显示层全繁 / 检索层双向 / 字表层取繁体正形）。

回归：20 条管线断言 + 100 条无头 UI 断言 + **669 条逐条对账**，全绿；
异体字归并 94 对，其中「啓/啟」「鼂/晁」「卽/即」都是这么逐个核出来的。

界面是纯静态 HTML，双击 index.html 就能用。
