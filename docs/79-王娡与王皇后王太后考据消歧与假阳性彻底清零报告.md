## 一、问题背景与原委

用户提出反馈：**「王娡 很多是错的」**。

经全量语料对账排查，确认原索引系统中关于汉武帝生母、汉景帝皇后王娡（`p_wangzhi`）的标注存在严重的假阳性污染：
1. **数据事实**：前四史与晋书正文中，**「王娡」本名出现次数为 0**（本名出自东汉王符《潜夫论·志氏姓》及后世索隐注引，五书正文全称皆为“孝景王皇后”或称“王太后”、“王皇后”）；
2. **错误根源**：原权威源将裸词「王皇后」和「王太后」粗放登记为 `p_wangzhi` 的核心别名，由于缺乏跨书时代收束与精细上下文消歧，导致其名下原本的 60 处命中中，有多达 **41 处（>70%）为假阳性**；
3. **被误吞对象**：
   - **汉元帝皇后王政君**（成帝母孝元王皇后/王太后，西汉末年掌权 60 余年，被大面积侵吞）；
   - **汉宣帝王皇后**（邛成太后，非王娡）；
   - **汉平帝王皇后**（王莽长女，非王娡）；
   - **魏王太后卞夫人**（曹丕即魏王位尊母亲卞夫人为王太后，非王娡）；
   - **西晋 5 位王皇后**（文明王皇后王元姬、哀靖王皇后王穆之、简文顺王皇后王简姬、孝武定王皇后王法慧、安僖王皇后王神爱）；
   - **十六国 3 位天王皇后**（后赵石虎立郑氏为天王皇后、杜昭仪为天王皇后；前秦苻健立妻强氏为天王皇后）；
   - **南越国樛太后**（南越王赵兴之母樛太后/摎太后，史记/汉书各 6~7 处）；
   - **汉晋各诸侯国太后**（齐王太后、梁王太后、代王太后、鲁王太后、东平王太后、中山王太后、定陶共王太后等）。

## 三、治理全景方案与工程实施

为了将这 41 处假阳性彻底拔除，同时保证真正属于王娡的 19 处 100% 召回，并在全库中对王政君等后妃正名，系统采取了以下四层联防机制：

### 1. 权威源别名对齐（`workbook/persons.xlsx`）
- `p_wangzhi` 别名配置为：`孝景王皇后|景帝王皇后|王皇后|王太后|膠東王太后|王娡`；
- `p_wangzhengjun` 别名配置为：`孝元王皇后|元帝王皇后|孝元皇后|王皇后|王太后|元后|王政君`；
- 满足管线 `declared_owner` 契约，使二者均成为泛称候选题中应有之义。

### 2. 停用词守卫升级（`pipeline/annotate.py`）
- `ALIAS_STOP_PRE["王太后"]` 扩充诸侯国名前缀与爵位前缀：`太齊齐梁代魯鲁東东平中山定陶膠东胶东南越魏巴蜀趙赵淮孝恭共侯`；
  - 阻断“太王太后”、“齐/梁/代/鲁/魏王太后”、“中山孝王太后”、“定陶共王太后”、“鲁恭王太后”等诸侯王太后截出裸词；
- `ALIAS_STOP_PRE["王皇后"]` 扩充诸侯/天王及各代谥号前缀：`天齊齐孝文明哀靖簡简文定安陳留陈留太宣平順顺僖留`；
  - 阻断“天王皇后”、“齐王皇后”、“文明王皇后”（王元姬）、“哀靖王皇后”（王穆之）、“顺王皇后”（王简姬）、“定王皇后”（王法慧）、“僖王皇后”（王神爱）、“陈留王皇后”以及“孝宣王皇后”、“孝平王皇后”截出裸词；
- `ALIAS_STOP_POST["王太后"]` 增加 `儀仪`，拦截“诸侯王太后仪”；
- `ALIAS_STOP_PRE["孝元皇后"]` 增加 `爲为氏`，拦截后汉书灵帝纪中“追尊皇祖为孝元皇，夫人夏氏为孝元皇后”误归王政君。

### 3. 泛称字典多维分书与上下文判定规则（`pipeline/build_dict.py`）
- **`GENERIC_MANUAL` 声明**：`王皇后` 与 `王太后` 并列登记；
- **`GENERIC_BOOK_CANDIDATES` 分书收束**：
  ```python
  "王皇后": {
      "sj": ["p_wangzhi"],
      "hs": ["p_wangzhi", "p_wangzhengjun"],
      "hhs": ["p_wangzhi", "p_wangzhengjun"],
      "sgz": [],
      "js": [],
  },
  "王太后": {
      "sj": ["p_wangzhi"],
      "hs": ["p_wangzhi", "p_wangzhengjun"],
      "hhs": [],
      "sgz": [],
      "js": [],
  },
  ```
  - 史记中收束至王娡；
  - 汉书与后汉书中由王娡与王政君并立；
  - 三国志与晋书中候选直接置空（魏晋王后不归汉代二人）；
- **`GENERIC_DEFAULT` 兜底**：`王皇后` 与 `王太后` 默认归王政君（西汉晚期王政君频次压倒性占优）；
- **`GENERIC_CONTEXT_RULES` ⓪ 级硬证据消歧**：
  - **王太后硬排除**（目标为 `None`）：
    - 南越樛太后：`南越`、`樛`、`摎`、`呂嘉`、`安國少季`、`王、王太后`、`嘉等`、`弱孤`、`越境`、`龍亢侯` 等；
    - 齐王尊鲁元公主为王太后：`城陽`、`尊公主`、`公主為`；
    - 梁王太后：`成陽邑`、`梁王`；
    - 淮阳王太后：`張敞`、`出游獵`；
    - 东平王太后：`東平`、`少加意`、`明察此意`、`強餐`、`慎疾自愛`；
  - **王娡定向命中**：
    - `槐裏`、`臧兒`、`金王孫`、`平陽公主`、`陽陵`、`景帝`、`孝景`、`田蚡`、`武安侯`、`條侯`、`竇太后`、`醫幸`、`義縱`、`姊姁`、`孝武皇帝` 等；
  - **王政君定向命中**：
    - `長樂宮`、`王莽`、`新都侯`、`王鳳`、`元帝`、`成帝`、`平帝`、`哀帝`、`丁、傅`、`傅太后`、`王舜`、`太子宮`、`甲觀`、`世嫡皇孫` 等。

### 4. 封国候选位阶守卫（`pipeline/build_dict.py`）
在修复过程中发现，原管线在根据封国核心词（如“胶东”）自动扩展候选人时，未严格隔离爵位身份（王 vs 侯 vs 太后），导致：
- 具有“胶东王太后”别名的王娡，以及具有“胶东侯”别名的贾复，被错误拉入 `膠東王` 的泛称候选人列表；
- 具有“中山太后”别名的冯昭仪被拉入 `中山王` 候选列表；
- `膠東侯` 被塞入多名胶东王。

**位阶隔离改造**：
在 `build_dict.py` 生成泛称候选时，记录 `(core, suf)`，强制约束：
- 泛称后缀为 `王` 者，候选人的核心别名不得以 `太后`、`侯`、`公` 结尾；
- 泛称后缀为 `侯` 者，候选人的核心别名不得以 `太后`、`王`、`公` 结尾；
- 泛称后缀为 `太后` 者，必须以 `太后` 结尾。
此项优化顺带彻底净化了 `膠東王`、`中山王`、`膠東侯` 等全库多处宗藩与外戚候选题。
