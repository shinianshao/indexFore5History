## #1 「有若 / 有子」大量错标（`待办`）

### 现象
用户报：「`有若` 除了《仲尼弟子列传》，其他可能都是错的」。

### 实测（`p_youruo` 共 103 处标注：有子 90 + 有若 13）

**真阳性 ≈ 8 处**
- `sj-067` 仲尼弟子列傳：`有若`×4、`有子避之`×1
- `hs-020` 古今人表：`有若`×1 —— ⚠️ **这一条是对的**（名单体例，「…晉籍談 子鼂 有若 子鉏商…漆彫啟 老子 師曠」，夹在孔子弟子群中，确是那位有子）
- `hhs-64` 吳延史盧趙列傳：`與有子先言「其為人也孝弟」`×1（引《論語》，确是有若）

**假阳性 ≈ 95 处**
- 别名「**有若**」8 处，全是「有＋若（＝像）」：
  `則有若伊陟、臣扈`（sj-034 ×3）／`未有若此者`（hhs-39）／`有若自然`（hhs-34）／
  `未有若公孫弘者也`（hs-058）／`未有若富平者也`（hs-059）／`未有若故丞相平津侯公孫弘者也`（sj-112）
- 别名「**有子**」约 87 处，全是「有＋子（＝儿子/孩子）」：
  `蜚廉復有子曰季勝`／`壽夢有子四人`／`有子而嫁`／`後宮非有子者`／`無有子`／
  `有子男一人`／`宋有子韋`／`楚有子玉得臣`／`南有子陽`／`江有子胥之神`／`將有子夫之變`／
  `有子權母`（子母錢）／`「幹父之蠱，有子，考亡咎」`（易引文）……

### 结论
- 用户判断方向对，但两处要修正：**`hs-020` 古今人表 是对的**；**问题主体是「有子」不是「有若」**（90 : 13）。
- 现有守卫挡不住：`ALIAS_STOP`（如 `老子`←父母）**只有前接**，而「有子」的假阳性前接无固定字
  （`廉/人/夢/建/王/相/無/非…`），得靠**后接**（`曰/五/四/一/而/者/男/名/枝/无…`）判；
  「有若自然」前后接都不在表内。

### 处理时机与方式
- **层次**：`annotate.py`（守卫表）+ `build_dict.py`（别名）。
- **时机**：归入「别名守卫补漏」一轮；因同在 `build_dict` 层，**建议与第 3 轮（人物 + 篇主表）合并**，省一次管线重跑。
- **候选修法**（择一，实施时定）：
  1. 撤掉「有子」别名（真阳性仅 2），给「有若」加前后接守卫；
  2. 给多字别名补一张 `ALIAS_STOP_POST`（后接守卫）——一劳永逸，但需回归全量别名；
  3. 章级白名单：`有若/有子` 仅认 `sj-067`、`hs-020`、`hhs-64`。
- **风险**：低。只动该人物的命中，不涉跨面。
- **验收**：`verify.py` 加断言（`有子` 不落 `復有子曰`/`有子四人`；`有若` 不落 `則有若`/`未有若；`hs-020`、`sj-067` 保底）。

## #2 索引排序默认「篇数」，可选「次数」（`待办`）

### 现象
用户：索引排序应默认按**篇数**，也可切换按**次数**。

### 实测
- `web/app.js:1263` `function byScopeCount(a, b) { return scopeStat(b).n - scopeStat(a).n; }`
  —— `.n` = 提及**次数**，即**当前就是按次数排**。
- 使用点：`renderPersonsIndex()`(1007)、分组(1049)、`initQuick()`(1266/1268)、tier 排序(732)。
- 文案 `app.js:1009` 写死「**按提及次數排序** · 懸停看全部」。

### 处理时机与方式
- **层次**：纯前端（`web/app.js` + `web/index.html`），**不动管线、零数据风险**。
- **时机**：**随时可做**；建议与 #3 同批（同改 `app.js`，免两次回归）。
- **做法**：加排序开关（篇数 / 次数），默认**篇数**（`scopeStat().c`）；五处使用点统一走一个 `byScopeSort`；文案随模式变；可用 `localStorage` 记住偏好。
- **验收**：`_ui_test*.js` 加断言（默认序＝按篇数降序；切换后＝按次数降序；标签与顺序一致）。

## #3 检索支持简体输入（`待办`）

### 现象
用户：检索时应支持简体（输入简体也能查到繁体正文）。

### 实测
- `web/app.js:1153` `normQuery()` **只走 `meta.variants`**，而该表是**异体字**表（`髙→高`、`巻→卷`），
  **不是简繁表**。实测 `meta.variants` 仅 **94 条**：
  ```
  汉→漢 ✓(碰巧收录)   刘→缺  东→缺  后→缺  张→缺  陈→缺  国→缺  马→缺  龙→缺
  ```
  → **简体输入基本查不到**（`刘邦` 查不到 `劉邦`）。

### 处理时机与方式
- **层次**：产物侧（`annotate.py` 带出映射）+ 前端（`app.js` 加候选）。
- **时机**：与 #2 同批；因需改产物，**必须重跑 `annotate.py`**。
- **做法**：
  1. 生成一份 **简→繁 字符映射**（OpenCC，约 2500–3000 字，估 30–60KB），随产物带出
     （如 `meta.simp2trad`，或独立小 js 按需加载）；
  2. `search()` 里把 `s2t(q)` 作为**并列的第三个候选**加入（现有已试 `q` 与 `qn`），**纯增量**，
     不替换、不反写正文 → 既有命中不会变差。
- **⚠️ 必守的坑**（`trad.py` 已踩过，直接借鉴）：
  - s2t **非幂等**（`單于→單於`、`十餘里→十餘裏`）；
  - **一简对多繁**：`后/後`、`里/裏`、`云/雲`、`发/髮·發` → 只作用于**查询串**，且**原串必须同时保留**试；
  - `trad.py` 的 `PHRASE_TRAPS` / `TRAD_FIXUPS` 机制可直接复用。
- **验收**：`_ui_test.js` 加断言（`刘邦`→劉邦、`张良`→張良、`汉书`→漢書 均命中；繁体输入结果不变）。

## #5 「暴桀」人工确认（`待确认`）

### 实测

| 卷 | 原文 | 当前标注 |
|---|---|---|
| `sj-075` 孟嘗君列傳 | 太史公曰：吾嘗過薛，其俗閭里率多**暴桀**子弟，與鄒、魯殊。 | 未标桀（只标了地名 薛/魯） |

### 结论
- 两处「暴桀」都是**「凶暴桀驁」的形容词**，**不是夏桀** → **现状（不标）是对的**。
- 原因：`annotate.py:221` `SINGLE_CHAR_PRE["桀"]` 里**已有「暴」**，前接「暴」一律不认。
- **注意这是单向守卫**：注释明确写了「若把暴并进双向表，`紂負桀暴之累`（夏桀之暴）会被一并挡掉」——
  所以 `桀暴` 仍判夏桀，只有 `暴桀` 被挡。

### 处理时机
- **无需改代码**。用户已确认两处「暴桀」均为形容词、现状（不标）正确。**已关闭**。

## C. 三国志官名 / 帝号 / 「启」错挂（`已修`，2026-09-23 晚）

> **用户报**：三国志人名索引错误太多，很多官名和称号对应的人不对，「启」也不对。

### 根因（实测）
1. **裸官名写进 `PERSONS.aliases`**：丞相/太尉/侍中/大將軍… 全局 core 匹配，整书挂到一人  
   （丞相→孙峻 210、侍中→韦曜 121、太尉→蒋济 87…）。`title` 字段本可展示，别名不必登记。
2. **帝号单人 core**：`文帝` 同时在曹丕与司马昭上，模式里后者占住 → sgz 全挂司马昭 177；  
   `武帝` 仅汉武帝有 → sgz「武帝太子」误挂刘彻。
3. **`p_qi` 单字「啟」全局**：sgz 42 处是「首啟/啟閉」动词，不是夏后启。
4. **书作用域缺口**：`p_liuxian_hhs` 无 `books` → `陳王` 抢走曹植；`p_liuze` 全局 → `琅邪王` 串进 sgz。

### 修法
- 剥离裸官名/裸将军/部分裸侯别名（title 保留）。
- `GENERIC_MANUAL`：`文帝/武帝/景帝/宣帝/陳王/關內侯` 多候选；`GENERIC_DEFAULT` 文帝→曹丕。
- `p_qi`：`PERSON_BOOKS_SJ=["sj"]`（多字别名仍在，单字只在史记）。
- `PERSON_BOOKS_HHS` 补刘羡；`PERSON_BOOKS_LIUZE` 限 sj/hs/hhs。
- `verify` 新增 3 条断言；泛称基线 **hhs≥45% / hs≥70% / sgz≥9% / sj≥75%**。

### 验收（已过）
- `run_pipeline --audit` 绿；`verify` **54/54**（文帝只曹丕、启 sgz=0、裸官名残留 0）。
- 探针：sgz core **多 pid 别名 0**；官名残留 0；`陈王` sgz→曹植 / hhs→刘羡。
- UI：`_ui_test` 61、地名 49、多书 41、csscheck 全过。

### 仍保留的口子（非阻断）
- sgz 裸 `武帝` 约 9/11 仍猜到刘彻（默认为汉武帝；量极小，武帝纪靠篇主/泛称已部分纠正）。
- `景帝/宣帝` 在 sgz 各 2 处走 era 到晋人物（原文多是汉景/汉宣追述）。
- `resolve` 仍报 13 个跨书侯王歧义（琅邪王/濟南王等，与本轮官名无关）。
