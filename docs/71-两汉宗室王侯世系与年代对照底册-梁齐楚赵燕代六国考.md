## 一、研制背景与消歧意义

中国正史断代史中，宗藩诸侯王存在极其普遍的“**同国号跨代世袭**”现象。当史家在正文中提及“梁王”、“齐王”、“楚王”、“赵王”、“燕王”、“代王”时，往往仅使用两字裸封号，未缀连谥号或人名。

在古籍索引与实体抽取系统中，若缺乏精确的代际消歧体系，会导致致命偏差：
1. **名气过大者全面侵吞后代**：如西汉梁国历经九代，但因梁孝王刘武声名显赫，导致元帝、成帝甚至东汉刘永、刘畅名下的史实全被误挂至刘武名下；
2. **跨朝代与跨政权割据混淆**：西晋司马肜、蜀汉刘理在正史中亦称“梁王”，若无断代史时代窗与篇目上下文守卫，极易产生年代倒错。

本底册系统梳理梁、齐、楚、赵、燕、代六大核心封国在两汉及魏晋的传承谱系、皇帝在位纪年、正典标志词与消歧规则，作为 BOOKINDEX 泛称消歧引擎的唯一权威事实依据。

## 三、消歧规则网构建体系（算法层映射规范）

基于上述世系底册，我们在 `pipeline/annotate.py` 与 `data/dict/people.json` 的 `genericAliases` 中建立三维消歧守卫规则：

```
[判定维度 1: 显式谥名绝对优先 (ctxRule / alias_pat)]
   例: "梁孝王" / "梁懷王" / "齊悼惠王" / "齊哀王" / "楚元王" / "趙幽王"
   → 长度优先，直接命中具体代际实体，禁止拆分或被裸封号掠夺。

[判定维度 2: 断代史时代窗与分书约束 (bookCandidates)]
   例: 《後漢書》中的「梁王」→ 严格限制候选为 [刘永, 刘畅]，绝不跨书落至西汉刘武；
       《晉書》中的「梁王」→ 严格锁定西晋司马肜，绝不落至两汉；
       《三國志》中的「梁王」→ 严格锁定蜀汉刘理或曹魏梁王。

[判定维度 3: 篇章上下文标志词硬证据规则网 (ctxRules)]
   例: 梁王
       - 邻域出现 ["彭越", "醢", "建城侯", "高祖五年~十一年"] → p_pengyue (梁王彭越)
       - 邻域出现 ["賈誼", "賈誼傳", "太傅", "墜馬", "傷死", "文帝二年~十二年"] → p_liuyi_hs (梁懷王劉揖)
       - 邻域出现 ["吳楚", "七國", "睢陽", "竇太后", "東苑", "鄒陽", "公孫詭", "袁盎"] → p_liuwu (梁孝王劉武)
       - 邻域出现 ["更始", "張步", "董憲", "蘇茂", "劉紆", "光武"] → p_liuyong_hhs (梁王劉永)
       - 邻域出现 ["章帝", "汝南王", "永平", "建初"] → p_liuchang_hhs (梁節王劉暢)
       - 邻域出现 ["司馬肜", "征西", "好畤", "周處", "賈后"] → p_simaxing (西晉梁王司馬肜)
```
