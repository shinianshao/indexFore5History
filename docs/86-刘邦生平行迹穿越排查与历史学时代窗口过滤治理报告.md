# 86-刘邦生平行迹穿越排查与历史学时代窗口过滤治理报告

## 一、问题背景与现象复现

用户在使用人物生平行迹舆图时反馈：
> 「刘邦，人物行迹图中还是有董卓列传，还有诸曹夏侯列传的内容」

经过全量回溯检索与数据对账，在修复前的刘邦生平行迹数据库中，确实存在以下严重违背历史事实的穿越记录：
1. **《后汉书·董卓列传》**（记录 ID: 5054-5056）：
   - 提取行迹：陇西、枹罕、河
   - 原文背景：`初，隴西人宗建在枹罕，自稱『河首平漢王』，署置百官三十許年。`
2. **《三国志·魏书·武帝纪》**（记录 ID: 5821-5823）：
   - 提取行迹：陇西、河、枹罕
   - 原文背景：`初，隴西宋建自稱河首平漢王，聚衆枹罕，改元，置百官，三十餘年。`
3. **《三国志·魏书·诸夏侯曹传》**（记录 ID: 5826-5828）：
   - 提取行迹：枹罕、凉州、河
   - 原文背景：`初，枹罕宋建因涼州亂，自號河首平漢王。`
4. **《三国志·蜀书·刘二牧传》**：
   - 提取行迹：广汉
   - 原文背景：`從事廣漢王累自倒縣於州門以諫`
5. **《三国志·魏书·明帝纪》**：
   - 提取行迹：吴
   - 原文背景：`戊申，追尊高祖大長秋曰高皇帝，夫人吳氏曰高皇后。`
6. **《晋书·载记第四》**：
   - 提取行迹：阳平、赵、魏、晋
   - 原文背景：`是歲，劉元海稱漢王于黎亭...`（十六国前赵刘渊称汉王）
7. **《晋书·载记第二十一》**：
   - 提取行迹：梁州、越
   - 原文背景：`期立，改封漢王，食梁州五郡...`（成汉李寿封汉王）

## 二、问题深层根因分析（双重病灶）

### 根因 1：底层实体识别层的多字别名子串截断与跨词粘连
1. **宋建自封伪号穿透**：东汉末年凉州枹罕军阀宋建（宗建）自封称号「河首平漢王」中包含了「漢王」二字。在无前缀阻断机制时，`漢王` 被匹配为刘邦（`p_liubang`），导致宋建在枹罕、凉州的割据据点全部被误识为刘邦的行迹。
2. **广汉人名跨词粘连**：益州从事「廣漢 王累」，地名「廣漢」与姓氏「王」粘连切分出「漢王」。
3. **亲属称谓与追尊穿透**：古汉语中「高祖父/高祖母」简称为「高祖」；魏明帝追尊曾祖父之父曹腾为「高祖大長秋」、「高皇帝」，表面词均触发刘邦别名。

### 根因 2：生平行迹抽取缺乏「史料时代窗口（Historiographical Era Constraints）」约束
- **本质区别**：`mentions`（全文提及）包含后人议论、策论、史臣曰、宗庙祭祀等；而 `person_trajectories`（生平行迹）**必须是人物在世时的真实物理时空轨迹**！
- 刘邦卒于公元前 195 年，生平正史详载于《史记》（高祖本纪）与《汉书》（高帝纪）。
- 《后汉书》（公元 25-220 年）、《三国志》（公元 184-280 年）、《晋书》（公元 265-420 年）相距刘邦过世数百年。其正文中出现的「高祖」全部为后人追述、引古策论（如荀彧「昔高祖保关中」）、帝王祭祖或十六国同名封王。
- 原抽取管线未设书目边界，盲目将后三书中的人地共现抽取为刘邦行迹，导致后三书中产生高达 154 条假行迹。

## 三、工程治理方案与两层落锁

### 1. 实体识别层（`pipeline/annotate.py`）
在多字别名守卫中建立双向前接/后接严格拦截：
- **`ALIAS_STOP_PRE`**：
  ```python
  # 漢王：排除宋建割據「河首平漢王」及「廣漢王累」等跨詞偽命中
  "漢王": set("平廣广"),
  "汉王": set("平廣广"),
  ```
- **`ALIAS_STOP_POST`**：
  ```python
  # 漢王：排除後接人名「漢王累」及「漢王府」
  "漢王": set("累府"),
  "汉王": set("累府"),
  # 高祖：排除曾祖父輩親屬稱謂（高祖父/高祖母）
  "高祖": set("父母"),
  # 劉季：排除同姓名人物（劉季陵、劉季緒等）
  "劉季": set("陵緒绪"),
  "刘季": set("陵緒绪"),
  ```
  *(注：对单字副词「大」保持豁免，确保「高祖大驚」「高祖大怒」「高祖大朝」等真实行迹不被误伤)*。

### 2. 生平行迹抽取层（`pipeline/extract_trajectories.py`）
建立全量 61 位核心历史人物的合法史料时代窗口映射表 `PERSON_VALID_BOOKS`：
- **史记组 10 人**（先秦、秦汉之交）：
  - 齐桓公、晋文公、秦始皇：`['sj']`
  - 刘邦、项羽、韩信、张良、卫青、李广、霍去病：`['sj', 'hs']`
- **汉书组 10 人**（西汉中期至新莽）：
  - 汉武帝、张骞、李陵、刘武、黥布：`['sj', 'hs']`
  - 王莽、苏武、汉宣帝、汉成帝、汉哀帝：`['hs']`
- **后汉书组 10 人**（东汉初至东汉中后期）：
  - 光武帝刘秀、公孙述、马援、班超、吴汉、王常、马武、邓禹、冯异：`['hhs']`
  - 董卓（汉末横跨）：`['hhs', 'sgz']`
- **三国志组 20 人**（汉末群雄与三国鼎立）：
  - 曹操、刘备、孙策、孙坚、袁绍、袁术、吕布、刘表：`['sgz', 'hhs']`
  - 曹丕、曹叡、孙权、诸葛亮、关羽、姜维、张辽、陆逊、周瑜、诸葛恪、张郃：`['sgz']`
  - 司马懿（曹魏权臣兼晋宣帝主）：`['sgz', 'js']`
- **晋书组 11 人**（两晋与十六国）：
  - 司马炎、司马睿、王导、谢安、石勒、石虎、桓温、刘曜、慕容垂、苻坚、王猛：`['js']`

在 SQL 抽取时强制注入 `AND ch.book_id IN (...)`，从物理机制上彻底终结任何跨朝代后世追述引发的行迹穿越！
