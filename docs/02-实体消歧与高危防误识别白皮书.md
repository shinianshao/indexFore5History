## 一、古籍实体消歧的核心矛盾与治理法则

古籍文本具有**字词界限无空格**、**一谥多帝/一号多王**、**文言动副词碎片撕裂**以及**跨朝代追述引用**等极端复杂的语言学特征。机械的分词与正则匹配必然带来海量假阳性。

BOOKINDEX 确立了七大层级消歧防护算法体系：

```mermaid
flowchart TD
    Raw[原始正文句子文本] --> L0[0. 字符级前置停用词与单字阻断]
    L0 --> L1[1. 前缀/后缀邻字守卫 ALIAS_STOP_PRE / POST]
    L1 --> L2[2. 长度降序最长匹配 (长名优先于短名)]
    L2 --> L3[3. 上下文硬证据判定 GENERIC_CONTEXT_RULES (年号/谥号/称谓)]
    L3 --> L4[4. 书籍作用域硬隔离 PERSON_BOOKS_* / ACCURACY_FIX]
    L4 --> L5[5. 篇目时代窗判定与追述择近算法 resolve_generic]
    L5 --> L6[6. 纯净实体命中落盘 (mentions 表)]
```

## 二、七大消歧防护核心算法

### 1. 裸帝号/裸王号 = 泛称动态消歧（绝不入单人 Core）
- **禁止原则**：严禁将裸“武帝”绑死汉武帝、裸“元帝”绑死晋元帝、裸“赵王”绑死张耳；
- **长名优先于短名**：
  $$\text{汉元帝}(3) \succ \text{元帝}(2)$$
  “汉元帝”直接归刘奭，“魏元帝”直接归曹奂，“晋元帝”直接归司马睿；只有脱离朝代前缀的裸“元帝”才进入泛称动态判定。

### 2. 上下文硬证据第一优先（Level 0 铁律）
在进行时代或统计归属前，优先扫描上下文微观硬证据（`GENERIC_CONTEXT_RULES`）：
- **年号硬证据**：
  - “元帝” + 景元/咸熙 → 锁定魏元帝曹奂；
  - “元帝” + 太兴/永昌/建武 → 锁定晋元帝司马睿；
  - “元帝” + 初元/永光/建昭/竟宁 → 锁定汉元帝刘奭；
  - “武帝” + 泰始 → 锁定晋武帝司马炎；
- **亲属称谓屏蔽**：
  - “高祖” + 曾祖/玄孙 → 判定为泛亲属用法，直接记 `None`（不误标为汉高祖刘邦）。

### 3. 前缀与后缀邻字守卫（ALIAS_STOP_PRE / POST）
阻断由于字面子串重合导致的断词撕裂与伪切：

    "齊王": set("冏倫乂"),

### 4. 二字文言语法虚词与动副词伪切词治理铁律
- **灾难根因**：古籍传记传首交代表字或本名后，正文从不直呼其字；若该字恰为古汉语高频动词或虚词（如宋昭公子得、宋平公子成、丁恭子然、包咸子良、姚泓元子），直接作为别名会引发毁灭性全库假阳性；
- **治理标准**：
  - 二字文言语法词、非人名政论词**绝不作为全局匹配别名**；
  - 从 Excel 别名列移除，规范维护在简介 `summary` 中（如`【本名：子杵臼】`、`字子然`、`字子良`），既保障前端简介可查，又彻底杜绝伪切词。

### 5. 跨朝跨书同名异人书籍作用域严格隔离（PERSON_BOOKS）

### 6. 时代窗判定与追述择近算法（`resolve_generic`）
在断代史中消歧同号人物时，遵循四步择近法则：
1. **本篇时代唯一候选** $\rightarrow$ 归他；
2. **追述择近**：若默认候选早于本篇，且存在时代接近候选（$\text{eraRank} \ge \text{here}-3$），归接近候选（如晋书中景帝归司马师，不归汉景帝刘启）；
3. **同代候选却落更早候选** $\rightarrow$ 记为 `guess`，绝不伪称 `era`；
4. **断代史索引分拆**：单选断代史时，索引拆为「本书记载时代 / 相对于本书的古人」两组分别排序展示。

### 7. 单字泛称防穿透与三道防线
针对大臣与帝王单字（如“汤”字）：
- **分书收束**：后三书单字“汤”强制收束为上古商汤，西汉大臣张汤、陈汤在后三书单字 100% 清零；
- **三道防线绞杀日常生活与医方用词**：
  - 阻断“汤药/汤液/沸汤/火齐汤/苦参汤/服汤”等医方词；
  - 阻断“汤沐邑/汤官/汤泉”等官职地名词；
  - 阻断“金城汤池/探汤/扬汤止沸/如汤沃雪”等成语。
