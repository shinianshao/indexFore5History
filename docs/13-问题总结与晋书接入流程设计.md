# 上篇 · 问题总结

## 1. 用户直接撞到的（产品层）

| 现象 | 根因 | 处置 |
|---|---|---|
| 默认四本全选，**多书合检灯不亮** | `allOn = 全选 && !peiOn`，默认开裴注把灯掐灭 | R0：只看书是否全选 |
| 点裴注**后面的统计不变** | 注文独立 `PEI_DATA`，永不进 `mentionCount`；开关只藏明细节 | R0：开裴注时 **处数=正文+注文**，后标 **【裴N】**；篇数仍正文 |
| 书栏「裴注」语义不清 | 只写「裴注」 | R0：改「**三國志裴松之注**」 |
| 点合检会顺手关裴注 | 状态机耦合 | R0：合检只全选书 |

## 2. 正确性事故（数据层）

| 现象 | 根因 | 处置 |
|---|---|---|
| **司馬懿 sgz 仅 9 处** | ① 正文多写「司馬宣王」未入库；② 泛称「宣帝/宣王」书过滤后单候选仍落 default（汉宣帝/周宣王）→ none/错归；③ `ERA_ORDER` 无「三國」era 档空转 | R1 + R4 |
| 仲達「登记了却 0 命中」 | 表面多在**裴注**；句层正文多写全名——不是匹配坏 | 断言改「名+字+裴注合计」 |
| 司馬炎/諸葛瞻整人缺失 | R3 速补未覆盖附传/后嗣 | 已补 |
| 官名挂到个人 | 裸官职进 `aliases` | #C + R3 再剥 28 条（**骑都尉**仅 `title`） |
| 曹操称谓少 | 阿瞞/魏武未收 | 已收；漢賊/奸雄/《曹瞞傳》**故意不进** |

## 3. 系统性债（词典完备度）

| 指标（史记标杆） | 后汉/三国问题 | R2/R4 后 |
|---|---|---|
| 双字「字」未收 | hhs 74/166、sgz 60/179 | 命中≥10 缺口 **5 / 1** |
| 薄别名 | 配角仅本名 | +119 字 + 尊称 |
| 附传缺人 | 合传次要人物 | +19（公孫淵/夏侯霸/劉巴…） |
| 泛称有依据 | sgz 26% | **82%**（含追述记 era） |

**一句话**：算法三层是稳的；债在「词典完备 + 产品状态机 + 泛称时代表」。史记显得好，是因为主路径早期手工补厚。

## 4. 方法论上值得记住的

1. **探针数字要读对语义**：「字缺×130」是该人命中数，不是表字频次（仲穎全书仅 2 处）。  
2. **`paragraph.text` 保留裴注 ≠ 句层有命中**：表面计数不能当标注数。  
3. **单候选泛称必须直归**：书过滤后只剩一人还走 default，是司马懿类事故的总根源。  
4. **时代表要覆盖全书朝代**：`ERA_ORDER` 缺三國，era 档整档静默失效。  
5. **验收靠断言不靠肉眼**：每坑一条 `verify`，本轮 58 → **74**。

# 下篇 ·《晋书》接入流程设计

> 原则不变：**换本书只换词典，三层算法一行不改**；每轮证明「既有四书逐 id 零回归」。  
> 本文是**晋书专用**流程 + 必守坑清单，操作细则仍见 `docs/05`（七步）与 `docs/09/10`（省 token 复盘）。

## 〇、晋书与前四史的差异（先想清再动手）

| 维度 | 三国志（已趟通） | 晋书（新难题） |
|---|---|---|
| 卷数 | 65 | **约 130**：帝纪 10 + 志 20 + 列传 70 + **载记 30** |
| 体例 | 国别史（魏/蜀/吴） | 纪传 + **载记**（十六国非正统）→ 篇主要按「帝纪/列传/载记」三套 |
| 注释 | 裴松之注（`〈…〉`，体量巨大） | 唐修《晋书》有**臧荣绪等旧史注/按语**；维基形态**必须探针**，勿假设同 `〈…〉` |
| 人名重叠 | 与史汉极重 | **与三国志极重**（司马氏、王谢、刘石等）→ `PERSON_BOOKS_JS` 比 sgz 更关键 |
| 时代 | 东汉末–三国 | **西晋 / 东晋 / 十六国** —— `ERA_ORDER` 已备 `三國/西晉/東晉`，需补 **十六国** 若词典用 |
| 地名 | 州郡 | 侨置郡县、十六国地名同名更凶 |
| 泛称 | 帝号/侯王 | 「**中宗**」「**元帝**」「**燕王**」「**凉王**」等跨十六国重复 |

**核心风险（按优先级）**  
1. **书作用域一刀切错**——司马懿/司马昭/王导/谢安 在三国志已有 pid，晋书必须 **复用同一 pid + `books` 扩成 `["sgz","js"]`**，严禁新建 `p_simayi2`。  
2. **载记篇主**——「刘元海载记」篇主是刘渊，不是晋帝；不得用帝纪谱系推。  
3. **注释/旧史按**——若维基用非 `〈…〉` 标记，单独剥；口径先问：**保留为注、不进正文统计**（与裴注/校勘同）。  
4. **ERA/泛称**——十六国君主「燕王/凉王/秦王」多朝重复，必须 `GENERIC_MANUAL` 多候选 + 书/篇消歧。

## 一、五轮总览（晋书专用）

```
第0轮 钉口径 ──▶ 第1轮 侦察·注册·抓取 ──▶ 第2轮 切分·注释隔离·篇主表
                                                    │
第5轮 字面·回归·验收  ◀── 第4轮 地名  ◀── 第3轮 人物词典+泛称 ◀──┘
```

每轮出口闸门必须是**可勾的数字/断言**；轮末 `run_pipeline` 或「只跑必要步 + 轮末全量」。

---

### 第 0 轮 · 口径（**已拍板 2026 用户**）

| # | 问题 | 拍板 |
|---|---|---|
| 1 | 载记算不算「书内篇目」？ | **算**，与本纪/列传同级入 `chapters`（category=`載記`） |
| 2 | 旧史注/按语 | **独立索引**（同裴注 `PEI_DATA` 模式：`JS_NOTE_DATA`） |
| 3 | 十六国人物 books | 见下「跨书 books 说明」；晋书侧新收默认 `["js"]`，与旧书共现则扩成完整列表 |
| 4 | 泛称正式基线 | **js ≥ 60%**（严于 sgz 35%，实施时 verify 钉 floor=0.60） |
| 5 | 注文 UI / 合计 | **由实施定**：与裴注同构——书栏「**晉書·舊史注**」胶囊；开启后处数=正文+注文并标 **【注N】**；篇数按正文 |

**跨书 books 说明（第 3 条展开）**  
词典里每个人物有一串 `books`，表示「这个人的别名**允许在哪几本书里匹配**」：

```text
曹操   books = ["hhs", "sgz"]     ← 后汉书、三国志都认
司马懿 books = ["sgz"]            ← 只在三国志认
王莽   books = ["hs", "hhs"]      ← 汉书+后汉书
```

- **同一人跨书只建一个 pid**，靠加长 `books` 扩展，禁止 `p_simayi2` 这种新建。  
- 例：司马炎已在三国志 → 接晋书时改成 `books = ["sgz","js"]`；谢安仅晋书 → `["js"]`。  
- 不写 `books` = 全局四书都能匹配（易抢同名，后汉/三国补人时禁止裸挂）。

**出口**：五条已写入本文；第 1 轮可直接开抓。

### 第 1 轮 · 侦察 + 注册 + 抓取

1. `data/dict/books.json` 加 `js`：`name=晉書`、`order=4`、**`ready:false`**。  
2. `fetch_book.py` 的 `BOOKS` 加 `"js": {"name":"晉書","prefix":"晉書/卷"}`（prefix 繁体）。  
3. `--map-only` 卷表：记录 **规范卷页数 / 重定向 / 非卷页**（校语、目录、载记别本）。  
4. **探针 2–3 卷 HTML**（必做，禁止套三国志正则）：  
   - 注释标记：`〈…〉`？`【…】`？`<small>`？按语「史臣曰」是否混入正文？  
   - 篇名：帝纪/列传/载记导航形态；「載記第一」类是否可自动抽。  
   - 简繁/异体混排量级。  
5. 全量抓取（抗限流 + 补抓）。

**出口闸门**  
- [ ] 篇名表条数 = 实测规范卷页数（不臆断 130）  
- [ ] 抓取 fail=0  
- [ ] 侦察报告四项：**卷数 / 注释标记 / 篇名可行性 / 正文·注规模**  
- [ ] 既有四书产物零改动（`ready:false` 贯穿全链路——见坑 #1）

**坑 #1**：`ready` 只在 `build.py` 挡不够，**每一个 `corpus_paths()` 调用方**都要 `ready_only=True`（hhs 接入时踩过，产物 `chapterCount` 被污染）。

---

### 第 2 轮 · 切分 + 注释隔离 + 篇主表

1. `build.py`：书注册表驱动；按第 1 轮探针定注释剥离：  
   - 同 `〈…〉` → 复用 `peel_angle_notes` / `keep_angle`；  
   - 不同 → **新函数**，在剥导航之后、抽段之前整页剥。  
   - **句层不得残留注标记**；`paragraph.text` 可保留注供读（同 sgz）。  
2. 篇名 classify：  
   - 帝纪 → `本纪`；列传 → `列傳`；志 → `書`；**载记 → 单独 category `載記`**（勿并进列传）。  
3. `build_dict.py`：  
   - `CHAPTER_OWNERS_JS`：**按卷 slug 显式列**，载记篇主=该政权君主/首领；  
   - `PERSON_BOOKS_JS` 空表 + 首批晋帝；  
   - 校验：键数 = volumes/js 条数。  
4. `sgz` 式跨书：**凡三国志已有 pid，晋书人物只改 `books` 扩展，不建新 pid**（坑 #2）。  
5. 轮末 `_snapshot_counts`：既有四书 **0 差异**。

**出口闸门**  
- [ ] 篇目数 = 卷表数；载记 category 正确  
- [ ] 注释/导航 **句层 0 残留**；注在 text/note 可读  
- [ ] 四书逐 id 零回归；`verify` 不少于现 **74/74**  
- [ ] UI 三套 + sweep（现 65/45/49）不降  

**坑 #2**：pid 撞车（顾雍/刘璋前科）。批量插入前 `seen_ids` 校验；`p_simayi` 等只改 `PERSON_BOOKS_*` 覆盖顺序（JS 表写在 SGZ 之后则覆盖——**或统一在汇总处 merge**，禁止静默覆盖丢一本）。

**坑 #3**：`PERSON_BOOKS` 多表覆盖时，`build_dict` 现是「后表覆盖前表」——晋书接入时把跨书人 **写成完整列表** `["sgz","js"]`，不要只写 `["js"]` 把三国志丢了。

### 第 3 轮 · 人物词典 + 泛称（含 #B 式单字守卫如需要）

1. **批量脚本生成**（`_gen_js_persons.py` → 插入，禁止逐条手写）：  
   - 帝纪诸帝 → 东晋诸帝 → 王谢庾桓 → 载记十六国君主/谋臣 → 列传附传滚补。  
2. 别名铁律（docs/12 已拍板，继续有效）：  
   - 只写**繁体**；双字表字 + 尊称白名单；  
   - **禁止裸官职**（丞相/車騎將軍/騎都尉…）进 core；官+专名可留（如「王丞相」若语料强专属）；  
   - 帝号/庙号/追尊走 `GENERIC_MANUAL`，不进单人 core（文帝前科）。  
3. 跨书扩 scope：司马炎/王导/谢安/桓温… 与 sgz/hhs 共现者写完整 `books`。  
4. 泛称：  
   - `GENERIC_MANUAL` 补「中宗/元帝/凉王/燕王/秦王…」多候选；  
   - 确认 `ERA_ORDER` 含 **西晉/東晉**（已有），若词典写「十六国」再补；  
   - **单候选直归**逻辑已具备，靠 books 过滤即可。  
5. `verify.py`：**js 泛称基线 floor=0.60**（用户拍板）；跨书人零回归断言（司马懿 sgz 仍 ≥18）。  
   若首轮实测 <60%，先补 `GENERIC_MANUAL`/篇主/era，**不降 floor**；仍不足则书面报告缺口再议。

**出口闸门**  
- [ ] 零命中人物 ≤3 且可解释  
- [ ] js 泛称 ≥ 实测基线；四书基线不降  
- [ ] 裸官职 core=0（含騎都尉断言保持）  
- [ ] 司马懿/曹操等跨书计数 **不因晋书归零或腰斩**

**坑 #4**：帝号「武帝」在晋书=司马炎，在史汉=汉武帝，在魏=曹操——**必须泛称 + books/era**，禁止任一人 core 独占。  
**坑 #5**：单字别名（「導」「安」等）默认不开；要开必须前接守卫 + verify 保底（#B 三件套）。
