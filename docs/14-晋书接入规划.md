## 2. 注释形态（可复用 `〈…〉` 剥离）

| 探针项 | 实测 |
|---|---|
| 标记 | **仍是 `〈…〉`**（与三家注/裴注同形） |
| 注文小字 | `<small …#996666…>` 有 |
| 样例 | `〈以下簡稱考異〉`、`〈以下簡稱局本〉`、校勘若干 |
| 非注标记 | `【】` 0；`{{}}` 几乎无；`&#91;1&#93;` 脚注实体；`[编辑]` 编辑链 |
| 「史臣」 | 卷二 1 处（史论，宜留正文） |

**结论**：注文剥离**可复用** `peel_angle_notes` / `keep_angle` 路径；  
**独立索引**可复用 `annotate_pei.py` 思路（产物如 `js-note-data.json`，UI【注N】）。  
`build.py` 另需剥：**姊妹计划/维基百科条目/参阅/閲文言**、`[编辑]`、样式块。
