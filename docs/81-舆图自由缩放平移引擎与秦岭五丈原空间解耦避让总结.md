## 二、地图平滑自由缩放与平移引擎（Zoom & Pan Engine）

### 1. 原生零依赖 SVG ViewBox 变换架构
为了保持脱机分发版（Static Bundle）绝对的**零第三方库依赖与毫秒级启动**，本方案完全采用原生 JavaScript 实现：
- **状态持久化与视口解析（`mapState.curVb`）**：
  引入 `parseViewBox(str)` 工具函数，将 SVG 视口统一解析为 `{ x, y, w, h }` 对象；
- **鼠标指针中心定点缩放（Wheel Zoom）**：
  监听 `stratMapSvg` 的非被动 `wheel` 事件（`{ passive: false }`，阻止页面误滚动），计算鼠标在当前 SVG 坐标系下的锚点坐标 `(mouseSvgX, mouseSvgY)`，使缩放始终以用户鼠标所指的地理位置为中心展开，缩放系数为 `0.82`（放大）与 `1.22`（缩小），缩放范围限制在宽度 `90`（约 11x 深度特写）至 `1400`（全景外延）；
- **平滑拖拽漫游（Drag Pan）**：
  监听 `stratMapBody` 的 `mousedown` / `mousemove` / `mouseup` 事件，根据屏幕位移与当前视口比例尺精确映射为 SVG 坐标增量，按住拖拽时动态切换为 `cursor: grabbing;`；
- **触控双指捏合与单指漫游**：
  完美支持移动端与平板触控（`touchstart` / `touchmove` / `touchend`），单指拖动平移，双指中心捏合缩放；
- **拖拽与点击互斥防误触机制**：
  当拖拽移动距离超过 4px 时，记录 `mapState.lastDragTime = Date.now()`；在点击要塞节点（`.map-hub`）时校验 220ms 冷却时间，彻底杜绝“拖拽地图松手时误选中地名展开考据卡”的误操作。

### 2. 悬浮极简古典控制器（`map-zoom-tools`）
舆图右上角浮动雅致控制组（带有毛玻璃半透明背景与细金边）：
- `[＋]`：以视口中心放大 20%；
- `[⟲]`：复位回当前选定战区的基准视界；
- `[－]`：以视口中心缩小 25%；
- 缩放比指示器（如 `100%`、`150%`、`260%`），直观反馈当前视野深度。

## 三、秦岭山脉与五丈原空间分层解耦避让

### 1. 地理关系与制图学解耦
- **地理事实**：秦岭山脉是东西横贯千里的大陆主干山系，南北分割黄河（渭河）与长江（汉水）流域；五丈原地处秦岭北麓、斜谷口北、渭河南岸的高台阶地。
- **视觉层级重构**：
  - **山脉作为自然面状背景**：将单一的点状图钉文字升级为沿山脉主脊走向横贯的半透明水墨大字距艺术字（`map-mountain-range`，`letter-spacing: 14px`，`fill: #36503c`，`opacity: 0.50`）；
  - **秦岭主脊坐标下移**：将「── 秦　嶺　山　脈 ──」精确定位在终南山、太白山以南的崇山峻岭主脊之间（`x = 295, y = 394`），既避开了北方的渭河谷地（`y ≈ 360`），也避开了南方的汉中盆地（`y ≈ 412`）；
  - **五丈原凸现为战术要隘**：五丈原保持在 `[107.75, 34.30]`（像素坐标 `x = 280.5, y = 362.4`），其要冲文字标注在圆点正上方（`y = 354.4`）；
  - **间距实测**：五丈原圆点与秦岭山脉文字的垂直落差达到 **32 像素**，文字之间落差达到 **40 像素**，彻底消除任何字迹遮挡！五丈原高台临渭河、南依巍峨秦岭的地理形胜关系鲜明呼应。
- **全图山脉统一样式雅化**：
  燕山山脉（`x=730, y=96`）、太行山（`x=525, y=225`）、大巴山（`x=220, y=452`）、大别山（`x=670, y=488`）全量采用水墨山脉艺术字，与高清地形底图浑然一体。
