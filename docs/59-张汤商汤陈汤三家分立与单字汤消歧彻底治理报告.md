## 一、背景与问题根因诊断

### 1. 用户反馈
用户在检索使用中敏锐指出：
> 「发现一个问题，张汤 的索引里，很多汤 的单字指的不是他，有汤药的意思，还有成汤的意思。」

### 2. 根因深度剖析
排查历史代码与正文标色发现，单字「湯」在系统中形成了严重的实体争夺与非人名穿透灾害：
1. **候选名单短缺与默认归属缺失**：
   - 历史代码在 `pipeline/build_dict.py` 的 `GENERIC_MANUAL["湯"]` 仅登记了 `["p_tang", "p_zhangtang"]`，完全遗漏了西汉同等声名显赫的名将**陈汤**（`p_chentang_hs`）；
   - 同时 `GENERIC_DEFAULT["湯"]` 为空，未指定中立兜底候选。
2. **断代史时空推断偏向灾难**：
   - 在《汉书》全书以及《史记》汉代武帝篇目中，由于张汤的朝代属性为“西汉”，算法在无显式上下文证据时触发“优先当朝人物”机制；
   - 导致《汉书·卷七十·陈汤传》中 74 处指代陈汤的单字「湯」全部被误算到张汤头上；
   - 导致西汉政论与经学追述“昔高帝之诛项籍，汤武之诛桀纣”、“商汤之德”等商汤名句，被全部抢夺给张汤。
3. **医药方技与日常生活词汇穿透（非人名误标）**：
   - 《史记·扁鹊仓公列传》及诸多医方记叙中出现的大量“火齐汤”、“和齐汤”、“汤液”、“汤熨”、“苦参汤”、“服汤二升”等医药方剂；
   - 成语与刑罚、地理词汇“金城汤池”、“沸汤”、“蹈汤”、“赴汤蹈火”、“汤沐邑”、“汤官”、“汤谷”等；
   - 因字符级守卫不全，单字「湯」被当作人名抓取并全部推给张汤。
4. **跨朝代后世断代史污染**：
   - 《后汉书》、《三国志》、《晋书》中大量探汤、扬汤止沸、医方等成语及商汤典故，亦被张汤跨书掠夺。
   - 治理前张汤名下被塞入高达 **642** 处提及（真实全名仅 69 处，多达 573 处单字伪命中！）。

## 二、治理体系与技术落地

为彻底根除假阳性，并建立不可动摇的防御基线，实施了四层立体治理：

### 1. 字符级邻字守卫增强（`pipeline/annotate.py`）
在正文切词层构建严格的非人名过滤防线：
- **`SINGLE_CHAR_STOP["湯"]`** 扩充排除非人名后续字：
  `"湯沐藥药液熨火池泉谷鑊镬旱沸濯溫温熱热寒劑剂官針针雪穀"`（全面防御汤药、汤液、汤熨、汤池、温泉、沸汤、烹刑镬、汤沐邑、官名汤官、水名汤谷、汤针等）；
- **`SINGLE_CHAR_PRE["湯"]`** 扩充排除动作与成语前接字：
  `"飲饮服進进煎柔嘗尝啜調调齊齐氣气沸蹈赴入熱热溫温冷清甘城金河浩波水趣合作為为易與与探揚扬如"`（全面防御进汤药、调齐汤、金城汤、沸汤、赴汤蹈火、探汤、扬汤止沸、如汤沃雪等）；
- **`SINGLE_CHAR_STOP2["湯"]`** 扩充双字停用词：
  `{"沐邑", "之邑", "之罪", "之刑", "池之", "池不", "液醴", "熨之", "鑊之", "镬之", "二升", "三升", "止沸", "沃雪", "令暖"}`。

### 2. 断代史分书收束铁律（`pipeline/build_dict.py`）
在 `GENERIC_BOOK_CANDIDATES` 建立明确的分书作用域：
```python
GENERIC_BOOK_CANDIDATES["湯"] = {
    "sj": ["p_tang", "p_zhangtang"],
    "hs": ["p_tang", "p_zhangtang", "p_chentang_hs"],
    "hhs": ["p_tang"],
    "sgz": ["p_tang"],
    "js": ["p_tang"],
}
```
> **铁律规范**：后三书（后汉书/三国志/晋书）绝非西汉大臣张汤或陈汤的时代，裸称一律收束为上古商汤（成汤）。后三书中张汤与陈汤的单字「湯」彻底 100% 清零。

### 3. 三家分立与上下文规则（`pipeline/build_dict.py`）
- `GENERIC_MANUAL["湯"]`: 补入 `p_chentang_hs`，三家平等竞争；
- `GENERIC_DEFAULT["湯"]`: 明确默认归商汤 `"p_tang"`；
- `GENERIC_CONTEXT_RULES["湯"]`：配置 25 项硬排除与各人物的强特征：
  1. **非人名词组硬排除（目标 None，最优先，scope 统一走 sent）**：
     `金城汤`、`汤池`、`汤药`、`汤液`、`汤熨`、`火齐`、`和齐汤`、`下气汤`、`苦参汤`、`柔汤`、`汤沐`、`汤镬`、`沸汤`、`趣汤`、`蹈汤`、`赴汤`、`汤谷`、`汤泉`、`汤旱` 全部排除；
  2. **商汤（成汤）硬证据（优先于后世大臣）**：
     `武/`、`、武`、`尧`、`禹`、`伐桀`、`放桀`、`放之`、`起于亳`、`以七十里`、`成汤`、`夏桀`、`夏台`、`胜夏`、`伊尹`、`亳`、`葛伯`、`契`、`纣`、`帝乙`、`汤誓`、`汤征`、`汤德`、`汤法`、`桑林`、`鸣条`、`祝网` 等；
  3. **陈汤（西汉西域副校尉，破郅支单于）硬证据**：
     `副校尉`、`甘延寿`、`延寿`、`郅支`、`西域`、`康居`、`乌孙`、`瑕丘`、`张勃`、`义成侯`、`斩单于`、`明犯强汉` 等；
  4. **张汤（西汉御史大夫/廷尉）硬证据**：
     `御史大夫`、`大夫汤`、`大夫臣汤`、`臣青翟、臣汤`、`廷尉`、`张汤`、`汤子卬`、`造皮币`、`盗孝文庙`、`劾汤`、`诛汤`、`逮汤`、`责汤`、`汤辩`、`汤奏`、`史谒居`、`朱买臣`、`赵禹`、`杜周`、`公孙弘`、`庄青翟`、`汲黯` 等。

### 4. 关键踩坑与规则边界修复
- **`scope == "window"` 的切词陷阱**：`match_ctx_rule` 在 `window` 模式下会把包含目标词的片段切掉。若规则词含有「湯」本身（如“苦參湯”），`window` 模式无法命中！**所有包含目标字本身的词汇规则必须使用 `scope == "sent"`**。
- **前接泛词陷阱**：若使用 `("pre", "臣", ...)` 会误判所有自称臣的句子（如“臣以为汤武复生”），必须使用组合专词 `("sent", "大夫臣湯", ...)`。
