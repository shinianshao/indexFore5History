# 别名守卫与泛称兜底

> 缘起：用户报了三类误标 —— ①单字「桀」被当成夏桀（豪桀／上官桀／桀溺／刘桀／暴桀／桀黠奴）；
> ②「老子」在「父老子弟／母老子弱」里被跨词切开；③「韓王」在战国诸篇被判给西汉的韩王信。
> 本文记录这三类的成因、守卫设计与验收口径。

---

## 一、三类误标的成因，各不相同

| 症状 | 真身 | 根因 | 属于哪一层 |
|---|---|---|---|
| 「桀」279 处里大半不是夏桀 | 豪杰义复合词 / 上官桀简称 / 他人 | **单字别名的语义歧义** | 别名匹配层 |
| 「老子」6 处落在「父老子弟」 | 「父老」+「子弟」被切开 | **多字别名的跨词切分** | 别名匹配层 |
| 战国篇「韓王」判给韩王信 | 战国历代韩君 | **泛称候选判不出，落到默认归属** | 泛称归属层 |

三类各修各的，不能混为一谈。

---

## 二、单字别名的守卫：双向、单向、后二字

引擎原有的 `single_char_ok()` 只有一张**双向**排除表（`SINGLE_CHAR_STOP`），
命中处前后各看一个字，查到了就否掉。「桀」一上来按双向表写，立刻踩了两个坑：

### 坑 1：同一个字两侧的反证不同，不能混进一张表

```
暴桀子弟   →  误（豪杰义）        前接「暴」该挡
紂負桀暴之累 → 正确（夏桀之暴）     后接「暴」不该挡
```

「暴」放进双向表，前者挡住了，后者也一起被挡 —— 真夏桀丢一处。

**修法**：拆成两张**单向**表，前接、后接各管一边。

```python
SINGLE_CHAR_PRE  = {"桀": set("豪俊儁雄暴陰軍官父侯劉疑與斬予立是後授僕封敢")}
SINGLE_CHAR_POST = {"桀": set("黠宋溺等子黨心追令因輒已奉頓常欲惡父驁妻")}
```

**定表的纪律**：先跑一遍全量命中，把每个命中处的**前字频次表**和**后字频次表**打出来，
逐字判断该字在哪一侧构成反证；判断完再用单元测试把两侧的边界案例钉死。
不要凭印象写表 —— 「雖」「紂」「之」三个字都差点被误挡：

```
雖桀紂惡不至於此、雖桀在上   → 用的正是夏桀（假设语气）
桀紂并称 28 处                → 最典型的正确语境
桀之時湯滅之、堯、桀之分       → 都是夏桀
```

### 坑 2：紧邻字是标点时，±1 字不够用

```
桀、安父子與大將軍光爭權
```

「桀」的前一字是顿号，不携带信息；真正能定性的是**后两字**「、安」（上官桀与其子上官安并称）。
±1 字守卫对此无能为力。

**修法**：加一张**后二字**表。

```python
SINGLE_CHAR_STOP2 = {"桀": {"、安", "為安", "爲安"}}
```

（「為安」「爲安」收的是「桀為安陽侯」那种封侯句式；异体「爲」需另列，因为查表用的是**原文**。）

### 复核：改完还剩什么

| 阶段 | 「桀」命中 | 说明 |
|---|---|---|
| 改前 | 288 | 279 处单字 + 8「夏桀」+ 1「帝桀」 |
| 首轮双向表 | 111 | 复合词基本清干净，上官桀简称仍漏 8 处 |
| 补单向 + 后二字 | **103** | 仅剩 3 处比喻用法（如「疆外之桀」，用夏桀指代凶暴），可接受 |

## 三、多字别名的守卫：防跨词切分

「老子」是两个字，走不到单字守卫那条路。而它的误配源是**跨词**：

```
父老子弟  =  父老 / 子弟   →  「老子」不是词
母老子弱  =  母老 / 子弱   →  同上
今父老子孫思我言          →  同上
```

真老子的前面从不接这两个字（「黃帝、老子」「問禮於老子」「老子曰」都不会）。

**修法**：新增通用函数 `alias_ok()`，单字走单字守卫，多字查 `ALIAS_STOP`：

```python
ALIAS_STOP = {"老子": set("父母")}      # 前接「父」「母」一律不认
```

原三处调用点（专属别名 / 篇内限定 / 泛称）统一改成调 `alias_ok()`，
从此多字别名也有守卫，不必再为每个案子单独打补丁。

## 四、泛称兜底：搬出「时代序」这把尺子

「韓王」**本来就在泛称机制里**（`GENERIC_CORES` 含「韩」，候选 11 人），
问题出在`resolve_generic()` 的最后一级：判不出上下文时，**一律落到 `GENERIC_DEFAULT`**。
而默认是韩王信（西汉）—— 战国篇的「韓王」于是整片错标 18 处。

### 4.1 候选先补全

词典原先**没有「韩王成」**。补上之后，秦末篇的 `era` 一级立刻能把他单挑出来
（他的时代是「秦末」，与韩王信的「西漢」不同），《項羽本紀》《留侯世家》《秦楚之際月表》的「韓王」随即归位。

### 4.2 兜底加一道闸：默认归属晚于本篇时代就**不标**

第一版写得过粗 —— 只看「默认归属与本篇时代不符」，结果《殷本紀》讲商代提「武王伐紂」，
周武王（西周）与篇内时代不符就被判 none，白丢 65 处；商汤同理。

**关键在于分清两种「不符」**：

```
默认归属 晚于 本篇时代   →  此人当时尚未出生，绝不可能是他  →  不标（none）
默认归属 早于 本篇时代   →  只是后人追述前朝，完全正常      →  照旧兜底
```

于是引入时代序：

```python
ERA_ORDER = ["上古","夏","商","西周","東周","春秋","戰國","秦","秦末","西漢","新","東漢"]
```

判据：`era_index(默认归属) - era_index(本篇时代) >= 2` 才判 none。

**阈值为什么取 2 而不是 1**：改朝换代处的人物本就跨在缝上 ——

```
《殷本紀》讲商代提「武王伐紂」   周武王比商晚一代（差 1）  正确
《夏本紀》讲夏代提「湯伐桀」     商汤比夏晚一代（差 1）    正确
《秦本紀》战国韩君却兜底韩王信   西汉比春秋/秦晚二三代    错误
```

取 1 会把前两种一起误伤（实测周武王丢 13 处、商汤丢 16 处），取 2 恰好分开。

### 4.3 none 不写标记，但计入统计

`none` 档**不写入索引**（前端不会显示错人），但计入 `tierStat`，
以便随时看到「有多少处是主动放弃判定的」。本轮 **208 处**（见 4.4）。

### 4.4 ★★ 补记：这道闸门曾整整空转了一轮（简繁不对撞）

上面 4.2 的写法**看着对，实际一次没生效**。

`ERA_ORDER` 按繁体写（`東周/戰國/西漢/東漢`），而人物词典的 `dynasty` 字段是
**简体**（`东周/战国/西汉/东汉`）。于是

```python
ERA_INDEX.get("西汉")   # → None     静默失败
ahead = ERA_INDEX.get(dynasty_of.get(entry["default"]))   # 恒为 None
if ahead is not None and here is not None and ...:        # 恒不成立 → 闸门空转
```

更阴的是它**不报错、也不显形**：`夏/商/秦/新` 这几个朝代简繁同形，照样能命中，
于是 `none` 档仍有 43 处产出，"看起来在工作"，把 bug 盖住了。
（`same_era == 1` 那条分支两侧同源，不受影响，`era` 档 401 处都是真的 —— 更容易让人放心。）
所以「韓王」在《秦本紀》《秦始皇本紀》《老子韓非列傳》《張儀列傳》里
照样兜底到西汉韩王信，一处没挡。

**修法**：所有跨表查朝代的地方收口到一个入口，内部先 `t2s` 归一：

```python
ERA_INDEX_S = {t2s(name): i for i, name in enumerate(ERA_ORDER)}

def era_index(name):
    if not name:
        return None
    idx = ERA_INDEX.get(name)
    return idx if idx is not None else ERA_INDEX_S.get(t2s(name))
```

**验收捷径 —— 看 `tierStat` 的联动**：闸门排在所有有依据档之后，
所以它真正生效时只可能把"本来要落到 `guess` 的"改判成 `none`：

```
guess  1064 → 899      （-165）
none     43 → 208      （+165，两档等量对冲）
owner/related/sentence/paragraph/chapter/era 六档：一个数都没变 ✓
```

六档里只要有**任何一档**变了，说明动的不是闸门，得重新审。
本轮同为 6 档不动（`era` 401 处不变），确认无误。

**同时补的两件事**：

- `韓王成` 增别名 `韓成`、`橫陽城君`（原只有 `橫陽君成`，两种写法都要收）；
- 新增 `韓王鄭昌`（故吳令，項羽立以拒漢）。别名**故意不写裸名「鄭昌」**——
  汉书另有涿郡太守鄭昌（刑法志）与谏大夫鄭昌（盖宽饶传），同形异人，
  裸名会把那两处一起吃进来；改收「韓王昌」「吳令鄭昌」（官称+名），正文里正好都这么写。

结果：`韓王信` 105 → **76**（并已并入三书产物），`韓王成` 24 → 27，
`韓王鄭昌` 新增 16 处 / 7 篇。

## 六、仍保留的口子

1. **「桀」剩 3 处比喻用法**（`疆外之桀`、`庶雄為桀`、`西羌侵邊為桀`）——
   修辞上以夏桀指代凶暴者，归夏桀可接受，未再细分。
2. **匈奴的「韓王」**（《衛將軍驃騎列傳》「獲屯頭王、韓王等三人」、《匈奴傳下》「左祝都韓王朐留斯侯」）
   是部落王号，仍兜底到韩王信。候选里没有匈奴王，暂不处理。
3. **《古今人表》未收录人名搜不到**：索引只写「命中句」，而 hs-020 有 1938 条人名条目、
   仅 924 条进索引（其余人名不在词典里）。这是设计使然，不是缺陷。
4. **「袖」的单字指代未接**：sj-040／sj-070 有「袖所言無不從者」这类单字用法，
   因「袖」同时是常用动词（袖金椎、把其袖），未开单字别名。
5. **《漢書》側「厲王」仍兜底到周厉王**（24 处）：候选刘长／刘次景并列，判不出。
   按「宁缺勿错」本可判 none，但会牵动既有断言，本轮未动。
