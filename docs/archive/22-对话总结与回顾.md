## 四、事故与教训

1. **单跑 `annotate.py` 把裴注账本冲掉了**（96,468 → 48,461 句）。
   标注必须四步连跑。已写进红线。
2. **断句只修了一半就报喜**。第二次被你提才发现还有一类。
   教训：修完要说清楚「修的是哪一类、还有哪一类没修」。
3. **第一版 `_audit_names.py` 八道闸太噪**：N1 把「周文王」「齊桓公」也打成问题，
   N6 命中 2335/2335（别名必含正名，本来就是设计如此）。
   教训：**判「是不是人名」不能只靠后缀正则，必须带语料上下文**。
4. **回退功能一版引入 UI 回归**（58/1，篇目一览被拉回人物页）。
   根因：`hashchange` 异步派发，自己写的 hash 也会回头触发重渲染。
   修法：`lastWritten` 去重——自己写的那次不重渲染，只有浏览器后退/手改地址才渲染。
