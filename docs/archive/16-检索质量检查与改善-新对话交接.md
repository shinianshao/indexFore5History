## 二、改善检索质量：推荐工作流

### 1. 抽查（只读探针，先证据后改码）

```text
pipeline/_probe_title_mis.py          帝号/王号/跨书错挂系统扫
pipeline/_probe_book_alias_density.py 分书别名密度
pipeline/_probe_alias_gaps.py         字/尊称/薄别名
pipeline/_probe_js_zaiki.py           载记专项
pipeline/_probe_report_quality.py     总量对照（史记标杆）
pipeline/verify.py --check            断言基线

pipeline/_gen_review_items.py --list  挑该人判的泛称（按 guess 处数降序）
pipeline/_gen_review_items.py --alias <称号> [--book <书>] [--per N] --out docs/17-条目-<批次>.md
                                     生成「带原文上下文」的人工判断条目
```

**抽查姿势**（UI 或产物）：
- 选单书 → 人物索引看「本纪时代 / 相对古人」两组是否合理  
- 搜长名（漢元帝/趙王倫/司馬宣王）vs 短名（元帝/趙王/宣王）  
- 对同一人跨书分账（诸葛亮 sgz/js、曹操 hhs/sgz）  
- 读全篇看高亮是否张冠李戴  

### 2. 问题分类 → 改哪一层

| 症状 | 改哪里 |
|------|--------|
| 某人搜不到 / 某书无条目 | `PERSONS` + `PERSON_BOOKS_*` **并集扩 books** |
| 称呼查不到（字/敬称） | `aliases` 补双字字 + 白名单尊称（**只写繁体**） |
| A 名归给 B | 泛称候选 / default / 长名 core / `ALIAS_STOP_*` |
| 子串误配（章武王→武王） | 长名 core 或 `ALIAS_STOP_PRE/POST` |
| 裸官名/裸帝号错挂 | 出 core → 泛称；官+专名可留 |
| 追述归到上古 default | `resolve_generic` 追述择近（`eraRank >= here-3`） |
| 时代窗分组不对 | `BOOK_ERA` / `eraRank` / 篇主强制 |
| 注文不算 | 开裴注/旧史注；或补 `annotate_pei` / `annotate_js_note` 词典同步 |

### 3. 回归链（每次改完必跑）

**推荐：一键脚本**（自动定位 python/node/jsdom、自动起停 8770 服务）：

```bash
bash scripts/run_all.sh            # 断言 → 字面层 → UI 四套（约 1 分钟）
bash scripts/run_all.sh --full     # 追加 _ui_sweep.js 全量扫描（慢）
bash scripts/run_all.sh --no-ui    # 只跑 Python 侧（改词典时的快速回路）
```

手工等价步骤（脚本失效时才用）：

```text
python pipeline/build_dict.py
python pipeline/annotate.py
python pipeline/annotate_pei.py
python pipeline/annotate_js_note.py
python pipeline/annotate_places.py
python pipeline/check_trad.py
python pipeline/verify.py --check
# UI（需 NODE_PATH=C:\Users\dell\.workbuddy\binaries\node\workspace\node_modules
#     且 web/ 起 http.server 8770）
pipeline/_ui_test.js / _ui_test_books.js / _ui_test_places.js
```

> 注意：python 必须挑**装了 opencc 的那个**（本机是系统 Python 3.12.10），
> PATH 上第一位的托管版 3.13.12 没装，`check_trad.py` 会假失败。

**改词典只跑 annotate 子集**；全量 `run_pipeline` 留轮末。

| 优先 | 状态 | 问题 | 线索 |
|------|------|------|------|
| P1 | ✅ 已修 | 裸短名错挂（高祖 js 兜刘邦/石勒、元帝落曹奐、惠帝落漢惠帝） | 长名 `高祖宣皇帝` + 分书收束 + `GENERIC_CONTEXT_RULES`（年号硬证据）|
| P1 | ✅ 已修 | 附传/类传长尾缺人（儒林/文苑/隐逸/艺术/载记从属） | 「X字Y」传主句式捞人，一次性补 322 人 |
| P2 | 待办 | 表字/尊称长尾（命中≥10 已清，≤10 仍有） | `_probe_alias_gaps.py` |
| P2 | 待办 | 泛称 guess 池仍大（合理追述 vs 真猜） | `tierStat` / 人物页「歸屬存疑」 |
| P2 | 待办 | 类传补人的**书外漏召**（限书闸门导致，实测 418 处） | `_probe_class_leak.py`；多数是同名异人，只能逐条判 |
| P3 | 待办 | 同名异地、单字地名误伤 | 既有限制；守卫表 |
| P3 | 待办 | 零命中人物 | 补别名或说明 |

改善时**每坑加一条 `verify` 断言**。条数以当次 `verify.py --check` 输出为准
（2026-09 P1 两项做完后为 89 条）。

### P1 两条的落地要点（别再走弯路）

**P1-a 裸短名**：不要改 default，改三样——
① **补长名**（`高祖宣皇帝`→司馬懿，长名优先自动接管裸「高祖」）；
② **分书收束** `GENERIC_BOOK_CANDIDATES`（js 惠帝只留司馬衷、元帝只留司馬睿）；
③ **上下文硬证据** `GENERIC_CONTEXT_RULES`（年号/亲属称谓），它排在**所有统计信号之前**，
且必须先于"按书 narrowing"，否则硬证据会被书作用域挡掉。

**P1-b 类传缺人**：靠「X字Y」传主句式捞（`X，Y人也` 噪声太大，默认关）。
- 生成器 `pipeline/_gen_class_fill.py --all --zi-only`，落地前先过
  `pipeline/_class_fill_prep.py` 剔噪声、避 pid 冲突。
- **人工必看**：自动抽会出「京兆尹防」（官名+名）、「甄豐校文字部」（动宾）、
  「觟陽鸿」截尾这类误抽，必须逐条看原文，别信自动结果。
- 补进来的异体字（鐘/卹/沖/鑒/説/勛）会触发 C 闸，登记进
  `TRADNAME_EXCEPTIONS` 第 ③ 类（以语料写法为正名），不要反过来改语料。
- **books 只给检测到的那一本书**。实测书外漏召 418 处里绝大多数是
  同名异人（張溫 hhs/sgz 两人、張玄 hhs/js 两人、魏桓 sj 另一人）
  和短语陷阱（史漢的「何曾」是副词），盲目扩 books 必引入误挂。

## 四、技能（新对话直接用）

| Skill | 用途 |
|-------|------|
| **`person-alias-coverage`** | 字/尊称/跨书 books 并集/长名/to_trad 不动点 |
| **`title-era-guards`** | 裸帝号泛称、长名优先、ALIAS_STOP、追述择近、BOOK_ERA 两组索引 |

路径：`.mimocode/skills/<id>/SKILL.md`

**铁律摘要**（详见 skill）：
1. 裸帝号/王号/官名 → 泛称或禁止 core  
2. 长名优先 + 前后接守卫  
3. 跨书只扩 `books` 并集，禁新 pid、禁后表覆盖  
4. `ERA_ORDER` 含三國/西晉/東晉/十六國  
5. 别名只写繁体；繁名 `to_trad` 不动点
