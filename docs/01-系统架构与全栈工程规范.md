## 二、三条不可逾越的工程红线

### 1. 绝对单向数据流原则
- **`workbook/*.xlsx` 是系统唯一不可再生的权威源**；
- 处理管线（`pipeline/`）对 Excel 只能**读取**，绝对禁止自动回写覆盖；
- 人工或 UI 的标错建议必须以「写入待生效纠错表 `overrides.xlsx` → 人工核验 → 重建管线生效」的形式流转，杜绝脚本脏写权威源。

### 2. 稳定三参数句子 UID 契约
- 句子主键 UID 算法强制规范为：
  $$\text{uid} = \text{md5}(\text{篇ID} \mid \text{段落序号} \mid \text{句子序号})[:12]$$
  **严禁包含句子原文文本**！确保当正文发生微调、勘误时，全局主键稳定不漂移；
- **拆句规范**：前半句继承原 UID，后半句分配新 UID；
- **并句规范**：保留首句 UID，被合并句标记为 `merged`；
- **弃用规范**：整句标记为 `dead`，永远不做物理删除，保证历史链接不悬空。

### 3. 业务规则与实体数据彻底解耦
- 泛称消歧、匹配规则、停用词、分词守卫维护在 Python 代码（`pipeline/build_dict.py`、`annotate.py`）；
- 实体正名、别名、朝代、关系边等实体数据维护在 Excel 权威源。

## 三、双账本机制与段落连贯性

1. **正文与古籍注文双账本彻底解耦**：
   - **正文账本**：223,164 句正文，统计实体频次与出现分布；
   - **裴注账本**（三国志裴松之注）：1,159 个注文段落、37.6 万字，独立统计 `annotate_pei.py`；
   - **晋书旧史注账本**：276 个注文段落、7,544 字，独立统计 `annotate_js_note.py`；
   - 注文统计结果不计入正文 `mentions` 总频次，避免史家注论稀释正史事实。
2. **注文段落 100% 跳转可达契约**：
   - 纯注文段落通过 `last_text_pseq` 锚定其所依附的正文段落；
   - 前端 `jumpToPara` 具备向前回溯兜底逻辑（`while (!node && cur > 1)`），确保用户点击注文能 100% 连贯跳转到上下文正文。
3. **长章节完整呈现**：
   - 后端 `chapter_sentences` 默认 `limit` 提升至 5,000 句，彻底解决《史记·十二诸侯年表》（3,454 句）等特大篇目被截断的历史缺陷。

## 四、存储派生层与脱机免服务分发

1. **SQLite 派生库结构（`data/index/index.db`）**：
   - `books`（5部）、`chapters`（564篇）、`sentences`（223,164句）；
   - `persons`（2,402人）、`mentions`（67,990处命中）；
   - `places`（1,620处地名）、`place_mentions`（118,177处命中）、`place_aliases`（2,643条写法）；
   - `relations`（101条活跃关系边）、`relation_evidence`（39条引文证据）；
   - `FTS5` 虚拟表提供高效全文搜索。
2. **免服务脱机快照（`dist/`）**：
   - `python app/tools/export_static.py` 生成脱机分发包；
   - 核心数据封装为 `dist/data.js`（29.9 MB），用户无需安装 Python、无需启动后端服务，直接在浏览器中打开 `dist/index.html` 即可流畅检索与阅读全部 564 篇古籍。

## 五、Windows 平台避坑与护栏规范

1. **`openpyxl` 安全写盘护栏**：
   - Windows 平台下，原生 `openpyxl.save(path)` 在临时目录受限或权限异常时，会先截断文件为 0 字节，失败后残留 2.3KB 损坏文件；
   - **严禁直接调用 `wb.save(path)`**，必须统一使用 `pipeline.common.safe_save_workbook(wb, path)`（内存 BytesIO 封包 + 临时文件原子替换 `os.replace`），写盘后必须校验文件大小 > 200,000 bytes。
2. **SQLite 文件句柄锁冲突**：
   - Windows 句柄机制严厉，当 8800 端口服务正在运行时，执行 `rebuild.py` 会因数据库锁报错退出（退出码 1）；
   - 重建索引前必须先终止后台 8800 服务，重建完成并导出快照后再行启动。
3. **解释器环境铁律**：
   - 必须使用系统原生 Python 3.12（`C:/Users/dell/AppData/Local/Programs/Python/Python312/python.exe`）；
   - 托管 Python 3.13 因缺少 opencc 会导致繁简七道闸假红。
