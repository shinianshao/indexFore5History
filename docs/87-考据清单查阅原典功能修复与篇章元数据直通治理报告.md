# 87-考据清单查阅原典功能修复与篇章元数据直通治理报告

## 一、问题现象与原因排查

用户反馈：
> 「现在人物行迹图下考据清单里的查阅原典功能没用」

经过检查前端 `app/web/app.js` 与数据流，精准锁定两大问题：

1. **未定义函数调用（ReferenceError 阻断）**：
   - 在前端点击事件监听器中，原代码执行了：
     ```javascript
     var jumpUidBtn = ev.target.closest ? ev.target.closest("[data-jump-uid]") : null;
     if (jumpUidBtn) {
       var jUid = jumpUidBtn.getAttribute("data-jump-uid");
       if (jUid) {
         jumpToSentence(jUid); // ❌ 全局未定义此函数！触发 ReferenceError 导致点击无反应
       }
       return;
     }
     ```
   - 系统原典阅读器跳转引擎的真名为 `openChapter(cid, uid, scope, pseq)`，需要同时传入篇章 ID `cid`（如 `sj-008`）与句子 UID `uid`。
2. **底层行迹数据缺乏篇章 ID（`chapter_id`）**：
   - 原 `person_trajectories` 表及导出的 `person_trajectories.json` 中仅包含了 `source_chapter`（篇章标题如“周本纪”），缺少对应的机读篇号 `chapter_id`（如 `sj-004`）；
   - 前端按钮仅绑定了 `data-jump-uid`，无法直接向 `openChapter` 提供所需的 `cid`。

---

## 二、修复与直通方案

### 1. 数据层与抽取管线直通补齐
- **数据库 Schema 扩充**：在 `person_trajectories` 表中增加 `chapter_id TEXT` 字段；
- **抽取脚本 `pipeline/extract_trajectories.py`**：在全量提取 61 位核心人物时，直接将查询到的 `ch.chapter_id` 注入结构并入库持久化；
- **脱机快照与 Excel 保持同步**：`data/index/person_trajectories.json` 与 `dist/data.js` 现已全量包含 `chapter_id`。

### 2. 后端 API 增加高容错兜底端点
- **`app/server/db.py`**：
  - 在 `person_trajectories(pid)` 查询中直接增加 `chapter_id` 返回；
  - 增加 `get_sentence_meta(uid)` 辅助函数，支持由任意句子 uid 秒查其所属篇章 `chapter_id`、原书 `book_id`、篇名与段号。
- **`app/server/main.py`**：
  - 新增轻量端点 `GET /api/sentence/{uid}`，为以后任意场景只凭单句 uid 直通原典提供双重安全兜底。

### 3. 前端交互接线与双端同构（`app/web/app.js` & `dist/app.js`）
- **按钮模板强化**：
  ```javascript
  '<button class="map-view-btn trj-jump-btn" data-chapter="' + esc(t.chapter_id || '') + '" data-jump-uid="' + esc(t.sentence_uid) + '" style="margin-left: auto;">查閱原典 ➔</button>'
  ```
- **点击接线闭环与事件冒泡阻断**：
  ```javascript
  var jumpUidBtn = ev.target.closest ? ev.target.closest("[data-jump-uid]") : null;
  if (jumpUidBtn) {
    if (ev.stopPropagation) ev.stopPropagation(); // 阻止冒泡，避免误触发条目地图聚焦
    var jUid = jumpUidBtn.getAttribute("data-jump-uid");
    var cid = jumpUidBtn.getAttribute("data-chapter");
    var targetScope = mapState.activeTrjPid || null;
    if (cid && jUid) {
      openChapter(cid, jUid, targetScope).catch(showErr);
    } else if (jUid) {
      // 容错兜底：若节点未带 data-chapter，异步调 /api/sentence/{uid} 获取后打开
      request("/api/sentence/" + encodeURIComponent(jUid)).then(function (info) {
        if (info && info.chapter_id) {
          openChapter(info.chapter_id, jUid, targetScope).catch(showErr);
        } else {
          alert("未查找到該句子所屬篇章：" + jUid);
        }
      }).catch(showErr);
    }
    return;
  }
  ```
- 打开原典时传入 `targetScope`（即当前行迹人物，如刘邦 `p_liubang`），使阅读器一开篇即自动高亮该句、平滑居中滚动、呈现呼吸灯动画，且上方自带人物相关段落筛选功能。
