# 人名筛查方法与原则（五书统一）

> 适用：史記 / 漢書 / 後漢書 / 三國志 / 晉書 全库人物词典。  
> 口径：**宁缺勿滥**——判不准先不入；已入的假名坚决删。  
> 关联：skill `person-alias-coverage` · `docs/17` 人工清单。

---

## 一、什么算人名（准入）

| 类型 | 例 | 条件 |
|------|----|------|
| 姓名全形 | 曹操、諸葛亮、公孫瓚 | 姓+名，2–3 字；或复姓+名 |
| 表字 | 仲穎、孟德、文遠 | **双字**；挂到对应人 aliases |
| 专名号 | 趙王倫、魏王丕、漢元帝 | **长名**优先；裸帝号/王号走泛称 |
| 官+专名 | 丞相斯、飛將軍 | 可 core（强专属） |
| 谥号全形 | 魯孝王、中山哀王 | 国+谥+爵**完整**形，可 core |

**不准入单人 core**：裸官职、裸帝号/王号/庙号（进 `GENERIC_MANUAL` 或不收）。

---

## 二、什么不是人名（排除闸，按序查）

### A. 形态闸（正则，先杀）

| 形态 | 例 | 处置 |
|------|----|------|
| `X太`（≤4字） | 東郡太、廣陵太、汝南太 | **拒**（太守截断） |
| `X校`（≤4字） | 越騎校、步兵校 | **拒**（校尉截断） |
| `X等` | 韓遂等、江京等 | **拒**（列表缀） |
| `X傳/詩/書/號/稱/騎/級` | 左氏傳、時人號、羊萬餘 | **拒** |
| 州部连称 | 徐二州、益二州、徐兗二 | **拒** |

> 例外白名单（真人勿杀）：鄭太、向長、蕭望之、費詩、杜詩、孫禮、孟子。

### B. 语义闸（子串黑名单）

含下列子串者拒：官职残片（太守/校尉/將軍/尚書…）、机构（尚方/國子/黃門…）、  
数量词（萬餘/將萬/一人…）、虚词词组（相與/終不/能直/何不/時人…）、  
书名（左氏/公羊/穀梁/毛詩…）、地名片段（黎丘/黎陽/於黎…）。

### C. 地名闸

串 ∈ `places.json` 名/别名 → **拒**（人名不得与地名表撞车）。  
同形确为人（如「韓信」vs 地名）靠 `books`/全名区分，不删真人。

### D. 尾字闸

末字 ∈ `侯王君公后尉書夫軍守尹正相國史令牧卿監等號稱騎級傳詩書` 且非白名单 → 拒。  
（防截断官职/封号尾巴。）

## 三、召回后必做（入典前）

1. **只取证不下判定** → 产出候选表（`extract_persons.py`）  
2. **去重**：同名 A/B/C/D 类只留一条 pid；跨书同人 **只扩 `books` 并集**  
3. **合并**：`Title+名` 紧邻既有全名 → 挂旧 pid 别名，不新建  
4. **繁名 `to_trad` 不动点**（`check_trad` A/C）  
5. **零命中复核**：入典后 0 命中 → 写法错/假名 → 删或改正名  
6. **每坑一条 `verify` 断言**

---

## 四、批量工具

| 脚本 | 用途 |
|------|------|
| `extract_persons.py` | 未覆盖串召回 A/B/C/D |
| `_gen_persons_fill.py` | 过滤 + 生成计划（含形态/语义闸） |
| `_apply_persons_fill.py` | 写入 build_dict |
| `_fix_false_persons*.py` | 假名批量清除 |
| `_probe_title_mis.py` | 帝号/跨书错挂 |
| `verify.py --check` | 回归断言 |

**原则**：复杂清洗写 `pipeline/_*.py`，勿 `python -c`；改词典只跑 `annotate*`，轮末全量。

---

## 五、拿不准怎么办

1. **能修** → 收长名/守卫/分书候选  
2. **仍歧义** → 进 `docs/17` 人工清单，等用户勾选  
3. **更难判** → **不入典** 或 标「未知」（`guess`/`none`），禁止硬归
