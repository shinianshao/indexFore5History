## 一、项目全貌与本质定位

### 1. 业务本质：五史实体索引与对照分析系统
本项目并非全文搜索（Full-Text Search）工具，而是针对《史记》《汉书》《后汉书》《三国志》《晋书》（共 564 篇、9.6 万句古籍）的**实体索引与篇目分层系统**。
- **别名归一**：精准归一古籍中的帝号、字号、官衔、专称（如《史记》无「刘邦」，全书作「高祖」「沛公」「汉王」「刘季」，全部归一）。
- **篇目分层**：区分「整篇讲述（专传篇主）」与「顺带提及（旁见逐句高亮）」。
- **古籍注释独立账本**：裴松之注（4,173 处）、晋书旧史注作为独立账本独立统计，不与正文命中混淆。
- **多维度扩展**：人物（2,240 人）、地名（1,575 处）、人物关系图谱（99 条规范边）。

### 2. 三阶段形态演进
1. **第一阶段（已废弃）**：微信小程序 + 微信云托管 + MeiliSearch。因微信云开发无持久化存储及架构重，于 2026-09-25 彻底叫停。
2. **第二阶段（已冻结）**：纯静态前端网页（`web/index.html` + `app-data.js` 30MB 大包），保留但不改交互。
3. **第三阶段（当前主力）**：**FastAPI（8800）+ SQLite 索引库（FTS5）+ Excel 权威源 + 离线静态快照（`dist/`）双轨并存**。

## 二、全栈技术架构与单向数据流

```
【权威源】workbook/*.xlsx (persons, places, overrides, sentence-edits, relations)
     │  （红线 1：单向数据流，人类/UI代写，后端管线绝对只读）
     ▼
【处理管线】pipeline/*.py (切分、打标、繁简规一、实体匹配、泛称消歧)
     │
     ▼
【存储派生】data/index/index.db (SQLite + FTS5 全文搜索)
     │
     ├──────────────────────────┐
     ▼                          ▼
【联机应用】app/                【离线快照】dist/
  - FastAPI 服务 (端口 8800)       - 预计算 JSON
  - RESTful API + 原生单页应用     - 双击即可脱机查阅
```

### 核心设计红线
1. **单向数据流**：Excel 为唯一不可再生权威源，pipeline 永不回写。若需保存，只能生成新版本或报差异。
2. **稳定三参数 uid**：句子主键为 `md5(篇|段序|句序)[:12]`（不含文本原文），拆句继承、并句留首标 `merged`、弃用标 `dead` 不物理删。
3. **规则进代码，数据进表格**：匹配规则在 `.py`，实体词典与关系在 `.xlsx`。
4. **UTF-16 码元与 Python 码位对齐**：古籍中非 BMP 字符通过 `hitSpan` A/B/C 三级回退处理，避免标色切片偏移。

## 三、当前现存问题与技术债台账

### 1. 系统与平台环境病（High Risk）
- **Windows 下 openpyxl 截断损坏权威源**：本机 Python `tempfile` 与权限受限时，`openpyxl.save()` 尝试写入文件会先将目标截断为 0 字节再因报错退出，留下 2.3KB 的损坏 xlsx 文件。
  - *防护规矩*：测试必须指定 `BOOKINDEX_OVERRIDES` 沙盒路径，每次运行完回归测试必须 `git status workbook/` 复核权威源 md5。
- **仓库根目录 4 字节 `blat` 文件泄漏**：Python 异常落盘造成的垃圾文件，需使用 `mv -n -t` 批量隔离清理。
- **SQLite 句柄独占导致重建失败**：8800 服务运行时锁死 `index.db`，重建前必须关闭后台服务。

### 2. 数据本体与人工裁决缺口（Business Debt）
- **17 组 / 35 人同名异人合并**：需人工查看古籍原文拍板（如刘焉在不同书被拆分了不同 pid）。
- **关系图谱 `rel_id` 键契约冲突**：`rel_id = md5(a|b|rel|era|book)`，68 条关系边缺失 `book`；若补充 `book`，将导致全部 `rel_id` 改变，破坏已有关联。
- **三国志段落缺失（P2-5）**：33 篇中有 304 处注文跳不到段落，如 `sgz-48` 语料有 47 段，落库仅 42 段，存在正文未落库缺陷。
- **docs/26 剩余 7 条人工关系待判**：需先补全 6 个库外人物。

### 3. 前端与交互缺陷
- **地名侧缺失「标错」入口（P8-b）**：人物命中已支持 hover 纠错，地名侧尚无前端修正面板。
- **双前端历史包袱**：根目录旧 `web/` 残留旧 bug，未来需正式物理归档或清理。
- **根目录 README.md 与现实严重脱离**：仍停留在 2026-09-25 旧版本，需更新。
