## 3. 工程消歧与深度避坑实录

在全量重建过程中，系统差异报告（diff report）敏锐捕获并彻底治理了两大深层别名冲突：

### 3.1 避坑一：“秦商”遮挡商鞅“商君”
- **现象**：差异报告显示 `[商君] sj-015 消失`（原句：“秦商君伐我，虏我公子卬”）；
- **根因**：原句为“秦[国] 商君[商鞅]”，孔门弟子秦商别名登记为“秦商”后，抢占了“秦”+“商”两个字，破坏了商鞅的历史命中；
- **治理**：孔门弟子秦商仅出现于《史记·仲尼弟子列传》，将其别名安全收拢为 `秦子丕|秦商丕`，彻底消除对“秦商君”的误占，商鞅命中 100% 恢复。

### 3.2 避坑二：“孔门郑国”抢占诸侯国“郑国”与水利“郑国渠”
- **现象**：孔门弟子郑国字子徒仅在 `sj-067` 出现一次，若别名裸收“鄭國”，全库 20 余处“郑国渠”和春秋战国诸侯国名（“郑国”）会被错误归为孔门弟子；
- **治理**：孔门弟子郑国 `p_zhengguo_sq` 正名“鄭國”，别名设为 `鄭子徒|孔門鄭國`，严禁裸收“鄭國”，确保水利工程与诸侯国实体 0 污染。

### 3.3 避坑三：字面层繁简不动点（OpenCC Fixups）
- 针对异体字“漆彫開”（史记原文）与“文醜”（后汉书原文），在 `pipeline/check_trad.py` 登记 `TRADNAME_EXCEPTIONS` 豁免，确保字面层 A–G 七道闸全绿；
- 针对孔门弟子“後處”（后处），正名统一使用繁体不动点 `後處`，别名覆盖 `后處|后处|後處|後处`，完美兼顾正典源文与显示规范。
