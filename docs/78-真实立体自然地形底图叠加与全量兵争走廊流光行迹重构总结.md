## 一、本次解决的三大核心问题与成因剖析

### 问题 1：地名说明文字高频闪烁（Flickering）彻底根除
- **根因剖析**：
  1. SVG 节点 `<g class="map-hub">` 由离散的圆点 `<circle>` 与文字 `<text>` 组成，两者之间存在透明间隙；当鼠标在圆点与文字缝隙中游走时，频繁在子元素间触发 `mouseover` / `mouseout`；
  2. 原 CSS 中存在 `.map-hub:hover .hub-text { font-size: 12.5px; }`，在鼠标处于文字边缘时，字号突变导致几何包围盒收缩/扩张，触发高频抖动；
  3. Tooltip 气泡直接定位在鼠标光标正下方，若缺乏偏移与延迟保护，容易遮挡光标引发事件穿透。
- **重构攻坚**：
  1. **底层隐形命中靶区（Hit Area）**：在每一个 `.map-hub` 最底层注入透明感应圆 `<circle cx="..." cy="..." r="18" class="hub-hitarea"/>`，彻底弥合空隙；
  2. **事件穿透隔离**：将 `.hub-ring`、`.hub-dot`、`.hub-text` 均设为 `pointer-events: none`，所有鼠标交互统一交由父级命中靶区处理；
  3. **移除几何抖动**：取消 hover 时的 `font-size` 突变，改用平滑的加粗与朱砂红字色高亮；
  4. **防抖与负偏移保护**：Tooltip 设置 `-14px` 垂直上浮负偏移，并在 `mouseout` 中增加 60ms 平滑延时，彻底根除闪烁。

### 问题 2：人物行迹图（以曹操为例）从离散 3 点到全量 27 要塞 25 走廊的飞跃
- **根因剖析**：
  1. 原 `export_static.py` 在导出人物关联地名 `D.p2pl` 时，硬编码了 `len(p2pl) < 8`；曹操一生涉足 272 处地名，前列被“魏、荆州、夏、陈、冀州、曹、江、兖州”等大国名州名占满，前 8 名里恰好仅有“邺（第3）、汉中（第4）、官渡（第7）”属于战略要冲；
  2. 导致洛阳、长安、濡须口、赤壁、彭城、南郡、襄阳、江陵、当阳、下邳、宛、合肥、白马、潼关、寿春、许昌、散关、陈仓、柴桑、延津、阳平关、成皋等 24 处关键要塞被误截断；
  3. 旧连线算法仅将离散的 3 个点连成一条横跨大半个中国的折线，脱离了真实战争走廊。
- **重构攻坚**：
  1. **全量战略要冲提取（`strategicHubs` / `p2strat`）**：建立专门的人物战略要塞提取管道，无条数截断限制，曹操涉足的全部 27 处核心要塞 100% 召回；
  2. **战略攻守走廊子网算法（Sub-network of Trajectory）**：遍历该人物涉足的全部要塞，只要两座要塞之间存在历史攻守通道（`connections`），即将其绘制为朱砂红动态流光虚线（`flowDash`）；
  3. **全景战争行迹呈现**：曹操行迹图呈现为**中原官渡决战走廊、徐州下邳走廊、河洛迎帝走廊、荆襄赤壁走廊、江淮合肥抗吴走廊、西征关陇汉中走廊**等 25 条历史名战通道交织的宏大网络，27 处要塞全部脉冲点亮！

### 问题 3：真实立体自然地形底图（Shaded Relief Basemap）抓取与重投影叠加
- **技术实现**：
  1. **权威数据源选型**：采用 ESRI World Shaded Relief（全球权威山阴立体晕渲高程切片服务），具备纯粹的自然山川地貌，**零现代国界省界、零现代公路、零现代文字杂质**，完美契合古籍历史沉浸感；
  2. **精确经纬度瓦片抓取**：编写 `pipeline/generate_terrain_basemap.py`，下载 Zoom 7 级别覆盖中国两汉三国核心区域（104.0°E~120.5°E，27.8°N~37.2°N）的 35 张高清瓦片；
  3. **严谨几何重投影**：将 Web 墨卡托投影（EPSG:3857）通过纬度非线性重采样，严格转换为与系统 SVG 对应的 Plate Carrée 等角矩形投影；
  4. **古典艺术调色**：去饱和微调对比度，将地形阴影映射为古典宣纸底色（`#FAF7F0`）与山水青黛墨色（`#555F62`），生成 2000×1240（2x Retina 超清，仅 234KB）底图 `terrain_basemap.jpg`；
  5. **图层融合与交互开关**：底图以 60% 适度透明度置于 SVG 最底层，并在工具栏新增【⛰️ 地形底圖：開/關】切换按钮，支持一键切换纯写意宣纸版与立体山川实景版！
