## 一、Round 4 攻坚背景与核心痛点

在中国古代前四史与晋书中，以梁、齐、楚、赵、燕、代为代表的六大核心封国，其同名封号跨越战国、秦汉、魏晋数百乃至上千年，历经十余代乃至数十位王侯世袭。在自动化实体识别与自然语言消歧中，此类封号存在长期难以根治的系统性顽疾：

1. **跨代侵吞与霸道垄断**：
   - 过去旧规则缺乏精细年代与上下文约束，导致大名鼎鼎者（如西汉梁孝王刘武、赵隐王刘如意）霸道侵吞全书同名王号；
   - 甚至《三国志》蜀汉梁王刘理、《后汉书》更始梁王刘永与梁节王刘畅，均被错误指向西汉梁孝王刘武；
2. **全库 0 标注盲区（楚王惨剧）**：
   - 全库检索“楚王”原先竟为 0 处标注。原因在于楚元王刘交仅登记“楚元王”、东汉刘英仅登记“楚王英”，没有一个实体在别名中直接登记裸“楚王”，导致权威源中缺乏该词条，泛称消歧引擎完全跳过；
3. **断词伪切撕裂（后汉书代王伪切）**：
   - 《后汉书》中频繁出现动词“代”接姓氏“王”的表述（如“五年春代王梁為前將軍”、“代王丹為太子太傅”、“而代王氏得其正序”），旧分词器将其硬切为封号“代王”，造成极其严重的假阳性伪切；
4. **单篇高频抢截（吕后本纪赵王偏位）**：
   - 在《吕太后本纪》中，宣平侯张敖因正名出现 3 次，导致旧篇目词频主导策略（`dominant`）被触发，将该篇刘如意、刘友、刘恢、吕禄等 5 代赵王的 26 处裸“趙王”悉数抢截。

## 三、架构改造与工程实施细节

### 1. 考据底册研制（`docs/71`）
系统研制了 3.2 万字权威底册《两汉宗室王侯世系与年代对照底册——梁齐楚赵燕代六国考》，系统理清了《史记·诸侯王年表》《汉书·诸侯王表》在位年号、汉高祖至汉武帝诸王分封流转脉络，并建立了系统实体唯一 ID（`pid`）对照表。

### 2. 权威源单向流对齐（`workbook/persons.xlsx`）
按照安全保存规范，使用 `common.safe_save_workbook` 为以下 6 位王侯原子补齐关键别名：
- `p_liujiao`（楚元王刘交）：追加 `楚王`；
- `p_liuying`（东汉楚王刘英）：追加 `楚王`；
- `p_zhangao`（赵王张敖）：追加 `趙王`；
- `p_liu_sui`（赵王刘遂）：追加 `趙王`；
- `p_lufang`（东汉代王卢芳）：追加 `代王`；
- `p_liuli_sg`（蜀汉梁王刘理）：追加 `梁王`。
同步在 `pipeline/persons_data.py` 对齐别名映射。

### 3. 断词分词守卫强化（`pipeline/annotate.py`）
- **前缀阻断（`ALIAS_STOP_PRE`）**：强化梁王、齐王、楚王、赵王、燕王、代王前缀守卫，防止复合名被错切；
- **后缀阻断（`ALIAS_STOP_POST`）**：
  - 在 `ALIAS_STOP_POST["代王"]` 注入 `梁丹良敏龔龚暢畅氏`，彻底阻断《后汉书》动词“代”引发的伪切；
  - 注入六大封王长名后接单字名守卫（如“趙王倫”、“楚王英”等），杜绝长名被剥离破坏。

### 4. 泛称消歧规则网重构（`pipeline/build_dict.py`）
- **候选池与首选王解绑**：重塑 `GENERIC_MANUAL` 与 `GENERIC_DEFAULT`，六大封国按各朝各书分流；
- **分书分流矩阵（`GENERIC_BOOK_CANDIDATES`）**：
  - 《三国志》梁王独家绑定蜀汉刘理（`p_liuli_sg`）；
  - 《后汉书》梁王候选池精准设定为东汉刘永（`p_liuying_hhs`）与刘畅（`p_liuchang_hhs`）；
- **典籍语境细致考据网（`GENERIC_CONTEXT_RULES`）**：
  - 注入 325 条包含皇帝纪年、核心同框大臣、关键战役事件的⓪级硬证据；
  - 例如《吕太后本纪》中针对“趙王”建立“霸上/蚤起/起居飲食/不敢遣/幽死/梁王恢/趙王印/武信侯”等严密特征词链条，彻底粉碎单篇词频偏位。

### 5. 前端古典宗藩世系传承链条卡片（`app/web/app.js` & `app/web/index.html`）
在人物详情页中，为属于六大封国的王侯上线“宗藩世系传承”导航组件：
1. **三柱枢纽导航**：
   - 【前任】：展示上任王侯姓名、爵号与在位考据，点击平滑直达上任人物卡片；
   - 【本任】：以古法朱砂印泥金框高亮本任王侯，展示其正名与核心历史评注；
   - 【继任】：展示下一任王侯爵号与事迹，若无嗣国除则清晰标注【末任 · 國除為郡】；
2. **全景传承长轨**：
   - 完整陈列从先秦、秦汉至三国魏晋该封国全代次王侯节点；
   - 节点带激活态与鼠标悬停历史评注，点击任意王侯即可无缝切转全景视图并同步 URL 哈希；
3. **视觉雅化**：
   - 融入温润宣纸底、古法朱砂、黛墨宋体微排版，与全站古典雅韵风格完美融为一体。
