## 一、用户反馈与重构背景

在两汉三国兵争形胜矢量舆图（方案 A）上线试用后，用户提出了以下核心痛点与优化需求：
1. **「底层地形图非常不清楚」**：原地形底图对比度过低、暗部发灰、山川险隘模糊不清，且在 `#FAF7F0` 底色下被严重稀释冲淡，无法鲜明呈现山河形胜之险阻；
2. **「另外曹操在边疆和外族作战没画上，比如曹操的行迹图，只能看到邺，汉中和官渡之间的连线」**：
   - 曹操平生赫赫战功中的「北征三郡乌桓」（出卢龙塞、登白狼山、斩蹋顿、屠柳城、东临碣石）与「平定并州南匈奴」（下壶关、抚太原）；
   - 曹操西征凉州关陇、平定羌胡与宋建（定安定、拔天水、经略金城、破枹罕、抚武都氐羌）；
   - 上述边疆征战在原地图中未画出，旧地图北界仅至 `37.2°N`，西界仅至 `104.0°E`，辽西塞北与西北凉州被截断在视界之外，战略要塞库完全缺失相关边疆节点；
3. **「在地形图上用鼠标放在地名上，很多地名的说明文字会不停闪」**：鼠标滑过要冲地名时，浮动气泡（Tooltip）在文字笔画与感应圆点边缘反复触发 `mouseout`/`mouseover` 事件，导致高频抖动闪烁；
4. **「地图底层能不能从googlemap上抓取整体的地形图，并对应起来」**：需引入高分辨率无现代行政要素干扰的全球高精自然立体晕渲地形切片，并与中国历史地理等角矩形投影坐标实现数学级零像素误差对齐。

## 二、高精真实自然立体地形底图重构（`pipeline/generate_terrain_basemap.py`）

### 1. 全球无污染高清自然晕渲源与 Zoom 8 超采样
- **切片源选型**：选用全球学术权威的 **ESRI World Shaded Relief**（自然地形立体阴影晕渲切片），其特点是**完全剔除现代国界、省界、铁路、公路、现代城市注记等一切现代人文污染**，纯粹呈现地表山脉、峡谷、丘陵、平原的自然起伏与立体阴影。
- **坐标范围扩展**：
  - 经度范围：`102.0°E ~ 122.5°E`（东扩至辽东湾与碣石，西扩至陇右临洮、金城、枹罕）；
  - 纬度范围：`26.5°N ~ 43.2°N`（北扩至燕山以北、白檀、柳城、塞北草原，南至南岭以北）；
- **超采样瓦片拼接**：采用 Zoom 8 级别切片（经向 16 块 × 纬向 16 块，共 256 张瓦片），建立多线程异步下载与 `data/.terrain_cache/` 本地持久化缓存，总采样分辨率达 4096×4096，几何裁切重投影后输出 **2000×1360 (2x Retina 高清)** 底图。

### 2. 动态对比度拉伸与水墨古风阶调重映射
- **切片灰度压缩缺陷诊断**：分析 ESRI 原始切片像素发现，由于全球海洋与高原的基准设定，华北平原与太行秦岭区域的原始切片灰度集中在 `140 ~ 255` 的狭窄浅灰区间，直接渲染会导致阴影严重不足、泛白模糊；
- **全动态范围直方图拉伸**：
  引入 `ImageOps.autocontrast(gray, cutoff=0.5)`，将有效像素直方图动态范围彻底拉满至 `0 ~ 255`，使最深峡谷阴影降为纯黑，平原过渡带保留充足层次；
- **水墨古典阶调 S 曲线重映射**：
  通过非线性 S 曲线（Sigmoid 幂次加权），实现古典宣纸水墨风格：
  - 陡峭深谷暗部（如秦岭绝壁、太行八陉、阴山缺口）：压深至玄黑水墨（RGB `27, 25, 23` ~ `38, 35, 32`），山脊阴影挺拔深邃；
  - 华北平原、江汉平原、成都平原：温润过渡至暖宣纸原色（RGB `240, 236, 226` ~ `250, 248, 242`）；
- **前端透明度与视界适配**：
  - 地形底图显示透明度由原 `0.60` 提升至 **`0.88`**（暗调模式下 `0.78`）；
  - 前端底图尺寸（`width="1000" height="680"`）与投影变换实现精确点对点对齐，误差小于 0.1 像素。

## 四、Tooltip 悬停高频闪烁彻底消除

### 1. 闪烁根因定位
1. **感应区过小且未覆盖标签**：原先 SVG 仅在圆心放置 `r="18"` 的感应圆，而地名词标签（如「白狼山」）宽度超过 30px 且位于圆心上方。鼠标指针在文字笔画内部的透明间隙滑动时，瞬间脱离感应圆，导致浏览器高频抛出 `mouseout`；
2. **Tooltip 自身遮挡光标**：Tooltip 弹出的 HTML 气泡框边缘若偶尔碰触光标，会触发气泡自身的 `mouseenter`/`mouseleave` 事件，造成恶性事件争抢循环。

### 2. 根治方案
1. **感应区升级为全面包裹矩形（`hub-hitarea`）**：
   在 SVG 中将每个要冲的感应区替换为包裹圆点与文字的圆角矩形：
   ```svg
   <rect x="pt[0]-24" y="pt[1]-22" width="48" height="42" rx="10" 
         class="hub-hitarea" fill="transparent" pointer-events="all" />
   ```
   彻底覆盖鼠标进入地名文字及其圆点的全部有效区域，形成平滑的命中靶区。
2. **前端逻辑引入状态锁与 100ms 防抖（`app.js`）**：
   - 引入 `currentTipHub` 记录当前活跃要冲，只要光标在同一要冲感应区内微幅移动，绝不重复销毁与重建 Tooltip；
   - 移出感应区时启动 100ms 定时器防抖（`tipTimer = setTimeout(...)`），若光标在 100ms 内滑入相邻区域或微调则无缝承接；
3. **CSS 彻底禁止 Tooltip 接收鼠标事件（`index.html`）**：
   ```css
   .map-tooltip, .map-tooltip * {
       pointer-events: none !important;
   }
   ```
   确保 Tooltip 永远不会阻挡光标对 SVG 元素的感知，彻底根除闪烁。
