## 二、可通用经验（已写入 skills）

### skill `person-alias-coverage`（已扩充）
1. 裸官名/裸帝号 **禁止** 单人 core；官+专名可留  
2. 双字字 + 尊称白名单；「字缺×N」勿当字面频次  
3. 跨书只扩 `books` 并集，禁新 pid、禁后表覆盖  
4. 追述长名 `books` 要含后书  
5. 繁名 `to_trad` 不动点  

### skill `title-era-guards`（新建）
1. 裸帝号/王号 → `GENERIC_MANUAL` 多候选  
2. **长名优先** + `ALIAS_STOP_PRE/POST` 防子串  
3. 追述**择近**：有时代接近候选归他，不落上古 default  
4. `ERA_ORDER` 覆盖全部朝代  
5. `BOOK_ERA` 断代史两组索引（邻书 era **有意重叠**：新/東漢/三國）

### 别名守卫工具箱（跨书通用）

SINGLE_CHAR_PRE / POST / STOP / STOP2   单字

## 三、流程经验

1. **口径先钉死**（裴注独立索引、载记算篇目、泛称 60%）再动码  
2. **探针数字读对语义**（字缺×130 是命中数；paragraph.text 含注 ≠ 句层命中）  
3. **每坑一条 verify 断言**（58→75）  
4. **复杂 Python 写 `_*.py`**，勿 `python -c`（引号/正则被 PowerShell 吞）  
5. **UI 测试防千分位**：`×1,026` 被 `\d+` 截成 1  
6. 轮末全管线；改词典只跑 annotate 子集

## 四·补、P1 收尾这一轮（裸短名 + 类传缺人）

**裸短名错挂**（三条一起改，别动 default）
1. 长名 `高祖宣皇帝` → 司馬懿：长名优先自动接管「昔高祖宣皇帝…」，
   实测 4 处原本误归石勒/劉邦。
2. `GENERIC_BOOK_CANDIDATES` 分书收束：js 惠帝只留司馬衷（漢惠帝歸屬归零）、
   js 元帝只留司馬睿（曹奐 由 42 处降到 6 处，且全是景元/咸熙年号那几处）。
3. 新增 `GENERIC_CONTEXT_RULES`：年号/亲属称谓是**硬证据**，排在统计信号之前。
   ⚠️ 实现上必须先于「按书 narrowing」——写反了硬证据会被书作用域挡掉，
   第一次就是写反了，元帝还是落曹奐 46 处。

**类传/附传缺人**
- 用「X字Y」传主句式捞（`X，Y人也` 噪声太大，`--zi-only` 默认关掉），
  一次性补 **322 人**（嵇康/劉琨/祖逖/陸機/潘岳/葛洪/張華/鍾會 全都不在典）。
- 自动抽必出误抽，人工一定要看原文：「京兆尹防」（官名+名，人是司馬防）、
  「甄豐校文字部」（动宾）、「觟陽鸿」被截成「陽鴻」、「安孫遂」（安孫=田安之孫）。
- 异体字（鐘/卹/沖/鑒/説/勛）会触发 C 闸 → 登记进 `TRADNAME_EXCEPTIONS`
  第 ③ 类，**以语料写法为正名**，不要反过来改语料。
- books 只给检测到的那一本。漏召体检 `_probe_class_leak.py` 实测书外 418 处，
  绝大多数是同名异人（張溫 hhs/sgz 两人、張玄 hhs/js 两人）与短语陷阱
  （史漢的「何曾」是副词），**不能**用扩 books 来消。
