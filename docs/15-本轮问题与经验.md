## 二、可通用经验（已写入 skills）

### skill `person-alias-coverage`（已扩充）
1. 裸官名/裸帝号 **禁止** 单人 core；官+专名可留  
2. 双字字 + 尊称白名单；「字缺×N」勿当字面频次  
3. 跨书只扩 `books` 并集，禁新 pid、禁后表覆盖  
4. 追述长名 `books` 要含后书  
5. 繁名 `to_trad` 不动点  

### skill `title-era-guards`（新建）
1. 裸帝号/王号 → `GENERIC_MANUAL` 多候选  
2. **长名优先** + `ALIAS_STOP_PRE/POST` 防子串  
3. 追述**择近**：有时代接近候选归他，不落上古 default  
4. `ERA_ORDER` 覆盖全部朝代  
5. `BOOK_ERA` 断代史两组索引（邻书 era **有意重叠**：新/東漢/三國）

### 别名守卫工具箱（跨书通用）

SINGLE_CHAR_PRE / POST / STOP / STOP2   单字

## 三、流程经验

1. **口径先钉死**（裴注独立索引、载记算篇目、泛称 60%）再动码  
2. **探针数字读对语义**（字缺×130 是命中数；paragraph.text 含注 ≠ 句层命中）  
3. **每坑一条 verify 断言**（58→75）  
4. **复杂 Python 写 `_*.py`**，勿 `python -c`（引号/正则被 PowerShell 吞）  
5. **UI 测试防千分位**：`×1,026` 被 `\d+` 截成 1  
6. 轮末全管线；改词典只跑 annotate 子集
