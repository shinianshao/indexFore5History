## R0 · 前端书作用域 / 裴注状态机（P0-1 + P0-3）

**范围**：只改 `web/app.js`（必要时 `web/index.html` 一点文案）。零数据、零管线。

### 0.1 多书合检灯（必改）

**现状**（约 L210）：

```js
var allOn = scope.length === BOOKS.length && !peiOn;
```

**改为**：

```js
var allOn = scope.length === BOOKS.length;
```

**点击「多书合检」**（约 L217–219）**去掉** `peiOn = false`：

```js
if (code === "all") {
  scope = BOOKS.map(function (b) { return b.code; });
  // 不要动 peiOn —— 合检与裴注无关
}
```

**验收**：

- 默认（四本开、裴注开）→ 多书合检灯 **亮**，文案「同時選中 4 / 4 本」；
- 只选两本 → 灭；点合检 → 四本亮且裴注状态保持原值；
- `_ui_test_books.js` 增断言：`peiOn=true` 且 `scope` 全选时 `.all` 含 `on`。

### 0.2 `inScope` 收干净（必改）

**现状**（约 L148–152）：

```js
if (cid && cid.startsWith("sgz-") && peiOn) return true;
return !isMulti() || scope.indexOf(c.bookId) >= 0;
```

**问题**：`peiOn` 时无条件放行全部 `sgz-*`，与 `scope` 脱钩。

**改为**：

```js
function inScope(cid) {
  var c = chapterMap[cid];
  if (!c) return false;
  return !isMulti() || scope.indexOf(c.bookId) >= 0;
}
```

裴注行/块的显示继续只看 `peiOn && peiOf(pid)`，**不靠 inScope 搭车**。

### 0.3 裴注开关的产品语义（P0-3，方案 A 推荐）

在**不改 `mentionCount`**（保住全部存量断言）的前提下，让开关「有感」：

| 位置 | 改法 |
|---|---|
| 人物页 stats 行 | `peiBlock` 旁固定提示「注文不計入提及總數」；`peiOn=false` 时显示灰字「裴注已關閉」 |
| 人物页稱謂 chips | 开裴注时，在 chip 的 `×N` 后追加灰字 `注+M`（来自 `PEI_DATA` 若能按 alias 拆则给；给不出则只在整人行给） |
| 索引人物列表 | 开裴注且该人 `PEI_DATA.n>0` 时，名后灰角标 `裴·N` |
| 检索结果空态 | 已有「不在當前選中的書」；补「裴注已關閉，注文中提及不會出現」 |
| 书栏裴注胶囊 title | 写清：「三國志裴松之注 · 另計，不計入提及總數；開啟後人物頁多一組注文命中」 |

**若你更想要「含注合计」（方案 B）**：

- 人物页 stats 增加一行「含注合计 = 正文 N + 注文 M」，仅 `peiOn` 时显示；
- **仍不写回** `mentionCount` / 索引排序；
- 需要从 `PEI_DATA` 多带 `byAlias`（见 R1 可顺带做）。

### 0.4 裴注与 sgz 勾选联动（小修）

| 事件 | 期望 |
|---|---|
| 点开裴注 | 若 `sgz∉scope` 则加入 sgz（已有） |
| 取消 sgz | `peiOn=false`（已有） |
| **重新勾选 sgz** | **`peiOn=true`**（新增，对称） |
| 初始化 | 保持 `peiOn=true`（与产品默认一致） |

### 0.5 R0 出口闸门

- [ ] 默认态：四本 on + 裴注 on + 合检 on  
- [ ] 合检点击不改 `peiOn`  
- [ ] 取消/重选 sgz 与裴注对称  
- [ ] `_ui_test` / `_ui_test_books` / `_ui_test_places` 全绿（允许新增断言）  
- [ ] **不跑** `run_pipeline`（零数据）

**最可能的三类根因**（按优先级查）：

| 假设 | 查法 | 修法 |
|---|---|---|
| A. 字串进了 `GENERIC_MANUAL` / 被他人 aliases 抢 | 查 `build_dict` 仲達/宣帝声明 | 字只留 `p_simayi` core；宣帝保持泛称 |

| C. 匹配被更长别名/篇主路径吞掉或规范化漂移（達/达） | 查 `norm`/`to_trad` 后是否仍匹配 | 繁简都进 aliases（已有达/達则查 variants） |

   - 若引擎只支持单一 default → 扩展为 `GENERIC_DEFAULT_BY_BOOK`，或在 `resolve_generic` 对 `chapter.bookId=="sgz"` 时优先晋系候选；  
   - 时代闸：汉宣帝（西汉）vs 司马懿（三国）——篇内 era 本可分开，查为何仍猜到汉宣帝（多半是 default 无条件落地）。  
3. 史记/汉书「宣帝」命中**不得下降**（对账）。

### 1.3 补人（小而准）

| pid | 名 | 首批 aliases（繁体） | books |

### R1 落地记录（2026，已实施）

**根因**：
1. `resolve_generic` 书过滤后只剩一人仍走 `default`（宣帝 default=汉宣帝）→ sgz 判 none/错归；
2. `司馬宣王` 未进 aliases（正文 67 处全名形式）；裸「宣王」未把司马懿列为候选；
