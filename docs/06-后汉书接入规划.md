# 后汉书接入 · 5 轮规划

> 依据：`~/.workbuddy/skills/classical-text-person-index/`（SKILL.md 六阶段 + 8 步迁移
> 步骤 + `references/01/03/04/08`）、`docs/03`（汉书接入实战）、`docs/05`（新书接入清单）。
> 总原则不变：**换本书只换词典，三层算法一行不改**；每轮结束都必须证明「史记+汉书零回归」。

## 前置结论（细读 skill 后确定的）

1. **先侦察再动手**（阶段 0 不可跳过）：后汉书的卷目结构、注释形态、异体字频次
   都要先量化，不能套汉书的正则。
2. **书作用域是命门**：后汉书人物（东汉）与史记/汉书重叠**少**，但与未来三国志重叠**重**
   （曹操/袁绍/刘备/孙权都是东汉末人）。所以 `PERSON_BOOKS_HHS` 这道闸从一开始就要立，
   别等三国志接入时再来补。
3. **注释要剥，但形态待核**：后汉书本纪/列传有唐**李贤注**、志有梁**刘昭注**，
   与史记三家注（`〈…〉`）形态未必一致，第 2 轮先探针再定剥离规则。
4. **《郡国志》可直接复用方志补录流程**（`references/08`）：汉书《地理志》已趟通
   1175 县，后汉书《郡国志》照做，只是县数更少（东汉合并过郡县）。
5. **异体字要重扫**：东汉文献有新的异体/避讳字，`VARIANTS` 补对要逐个核"书中只有一义"。

## 五轮总览

```
第1轮 侦察·注册·抓取  ──▶  第2轮 切分·篇主表  ──▶  第3轮 人物·泛称消歧

第5轮 字面·回归·验收  ◀──  第4轮 地名·郡国志补录  ◀──┘
```

## 第 1 轮 · 侦察 + 注册 + 抓取（对应阶段 0 + docs/05 第 1–2 步）

**目标**：拿到后汉书全部语料，摸清卷目、注释、异体字三类实情，产出侦察报告。

1. `data/dict/books.json` 加 `hhs`（`ready:false`），`fetch_book.py` 的 `BOOKS` 加一条
   （`prefix` 用繁体 `後漢書/卷`）。
2. `fetch_book.py --book hhs --map-only`：先解析卷表——重定向、slug 形态（是否有
   `027下之上` 类）、非卷页（校语/叙例/别本）。
3. 写探针抽 2–3 卷看 HTML：李贤注/刘昭注用什么标记、正文在哪、篇名怎么取。
4. **阶段 0 量化**：繁体/简体/异体混排实测（仿 `references/07` 的 63 种/3269 次口径）、
   体例确认（纪传体 + 志 30 卷）、卷/篇/段/句结构。
5. 全量抓取（复用抗限流 + 补抓）。

**可验证产出**：`data/raw/hhs-*.html` + `volumes/hhs.json` 篇名表无空缺；
侦察报告给出「卷数、注释标记、异体字 TOP、篇名抽取可行性」四项结论。

**出口闸门**：篇名表与维基文库实际卷页对账一致；抓取 0 失败。

**出口闸门**：后汉书篇目数 = 卷表实测数（核验，不臆断 120）；切句后无残留噪声段

## 第 3 轮 · 人物词典 + 泛称消歧（对应 skill 阶段 2–4）

**目标**：后汉书人物全量收录，泛称消歧收敛。

1. 按篇补人物（东汉诸帝 → 云台二十八将 → 列传传主/附传），**别名一律繁体**、
   凡持称号必登记称号、官职词用 `OFFICE_WORDS` 剔除（`references/03` 三条硬规则）。
2. 泛称扩充：东汉「XX侯 / XX将军 / XX王」类同称异人比西汉更多，`GENERIC_MANUAL` /
   `GENERIC_CORES` 按体检报表滚动补，`GENERIC_DEFAULT` 手工纠正兜底。
3. 书作用域：后汉书人物全部 `books=["hhs"]`（与史记/汉书同名者尤其要标，避免跨书串味）。
4. 跑 `resolve.py` 体检 → 按报表补 → 收敛到只剩已知噪声（`implicit` 假警报）。
5. `verify.py` 为后汉书**单独设一条泛称分书基线**（先实测再钉死，不照抄汉书 60%）。

**可验证产出**：后汉书人物词典完整；泛称清单收敛；体检报告清空。

**出口闸门**：零命中人物 ≤ 3 且逐个可解释；泛称有依据占比达后汉书基线；
史记/汉书人物逐 id 零回归。

## 第 1 轮侦察结论（已完成，实测数据）

### 1. 卷目结构：120 卷 / 130 页

维基文库《後漢書》130 个规范卷页，对应通行本 **120 卷**，其中 10 卷被拆成上下
（卷 1、10、28、30、40、60、74、79、80、82 各拆上下 → 多出 10 页）。

| 部位 | 卷号 | 页数 | 说明 |
|---|---|---|---|
| 本纪 | 1–10 | 12 | 光武帝纪(上下)、明帝、章帝、和殇帝、安帝、顺冲质帝、桓帝、灵帝、献帝、皇后纪(上下) |
| 列传 | 11–90 | 88 | 8 卷拆上下 |
| 志 | 91–120 | 30 | 司马彪《续汉书》志，志第一至第三十 |

**志的卷号映射**：卷 91 = 志第一，卷 109 = 志第十九（郡国志一），卷 114 = 志第二十四
（百官志一）。**《郡国志》= 卷 109–113（志第十九至二十三）**。

### 2. 规模

- 正文（剥标签 + 剥注后）**1,190,064 字**；注文（`〈…〉` 内）**654,610 字**，
  注占约 35%——**必须剥离**（否则页面"原句"是李贤/刘昭的注）。
- 模板残留 46 处（`姊妹计划:数据项` 等），切分时要剔除。

### 3. 注释形态：可直接复用剥注逻辑

李贤注（本纪/列传）与刘昭注（志）**同样用 `〈…〉` 包裹**，与史记/汉书三家注一致。
抽样：`〈南陽，郡，今鄧州縣也。〉`（地理注）、`〈臣昭案：志猶有遺闕…〉`（刘昭案语）。
→ `build.py` 剥 `〈…〉` 的逻辑**无需改动**即可复用。

### 4. 篇名抽取：本纪卷要人工审读

导航条格式**不统一**：

- 列传卷（11+）：`劉玄劉盆子列傳` → 抽取**正确**。
- 本纪卷（1–10）：导航条是 `後漢書卷一上‧光武帝紀第一上`（卷号带上下 + `‧` 分隔）、
  `後漢書《志》第十九郡國一司隷`（志卷无「卷」字，用「《志》第X」）→ 现有
  `parse_title` 抽得**不干净**（实测 `2 → ·帝紀第二顯宗孝明帝`、`3 → 肅宗孝章帝紀三`）。

**处置**：篇名表 `volumes/hhs.json` **人工审读修正**（120 卷篇名是已知的、权威的，
比抽取更可靠）——符合项目规矩「挖掘器只负责召回，精确性由人审读」。归第 2 轮。

### 5. slug 无零填充 + 卷区分隔符

- slug 是 `1上` / `2` / `10下`（**无零填充**，不同于史记/汉书的 `001`）；
  `fetch_book.py` 的 `sort_key` / `slug_number` 用 `\d+` 提取数字，**能正确处理**。
- 重定向 3 个（`卷1→卷1上`、`高句麗傳→卷85`、注序简繁重定向），非卷页 1 个
  （`注補續漢書八志序`，刘昭注序，正确排除）。

### 6. 异体字：VARIANTS 表基本覆盖

史记/汉书的 94 对 `VARIANTS` 在后汉书正文里**大面积命中**，可直接沿用：
于 916、云 797、余 476、閒 358、雒 214、阳 194、将 188、説 170、时 138、无 134、
羣 121、内 120、黄 115、军 95、彊 78、鄕 71、戸 65…
→ 归一表无需重建；后汉书**独有**的新异体/避讳字留待第 5 轮细扫
（判据仍是「书中只有一义才收」）。
