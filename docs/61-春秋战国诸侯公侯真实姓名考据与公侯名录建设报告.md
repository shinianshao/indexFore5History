## 一、背景与目标

古籍中春秋战国人物多以爵位、国号、谥号或行辈指代，如“齐桓公”、“晋文公”、“秦穆公”、“魏文侯”、“赵武灵王”、“信陵君”、“平原君”、“公子纠”、“公孙衍”等，缺乏真实姓名（姜小白、姬重耳、嬴任好、魏斯、赵雍、魏无忌、赵胜等）。这导致用户在根据历史真实姓名检索时常常扑空；同时，宗室公侯数量庞大，在人物索引全览中占据大量篇幅。

**用户明确提出三项核心诉求：**
1. **真实姓名直接检索**：所有诸侯国君、公子封君在检索中均能使用其真实姓名（本名）直接检索并准确定位对应人物；
2. **公侯名录独立分类**：在前端人物索引中将诸侯公侯单独分类呈现（或提供“公侯名录”独立分类视图），与普通名臣将相区分；
3. **计数规则严格不改动**：正文中的提及与打标计数规则（mentions）严格保持历史既有口径，绝不因补充真实姓名别名而引发语料虚假碰撞或破坏既有统计。

## 三、双轨隔离机制与伪命中阻断

为坚决守住“**计数的规则不改动**”这一铁律，我们建立了严格的检索/正文双轨机制与词法守卫：

### 1. 裸双字谥号守卫 (`BARE_TITLES`)
过滤全部 28 个双字裸谥号（如 `莊公/庄公/文公/武公/景公/靈公/灵公/桓公/惠王/哀王/成公/昭公/孝公/平公/穆王/定王` 等），绝不作为个人 core 别名灌入，避免单个诸侯通吃全书所有篇章。

### 2. 词法边界伪命中阻断
在全量语料对账中，精准发现并拦截了多起由短名引起的假阳性误伤：
1. **齐桓公移出裸 `'小白'`**：阻断周本纪“小白之旗”非人名误标；检索“小白”由 `姜小白/公子小白` 字符串逻辑无损召回；
2. **公子郢移出裸 `'子南'`**：阻断殷本纪“子南庚”商王误标；
3. **商纣王移出裸 `'子受'`**：阻断“小子受先功”非人名误标；
4. **周襄王与卫成公移出裸 `'姬鄭/姬郑'`**：彻底阻断“幸姬郑袖”、“宠姬郑袖”等以“宠姬/侍姬 + 郑姓”构成的跨词误标，收复屈原列传与张仪列传中楚怀王宠姬郑袖真阳性；
5. **鲁定公移出裸 `'姬宋'`**：阻断卫康叔世家“公欲去诸大夫而立宠姬宋，大夫共诛姬宋”中卫惠公宠妾（姬宋）对鲁定公的误标；
6. **齐懿公与晋怀公同名实体边界厘清**：`p_qiyigong` 移出 `公子商人`，由 `p_gongzishangren` 保持命中；`p_jinhuaigong` 移出 `公子圉`，由 `p_gongziyu` 保持命中；`p_songyuanwang` 移出 `宋元公`，由 `p_songyuangong` 保持命中；使全系统“零命中人物”精准稳定在 5 人基准线。

## 四、前端呈现层与公侯名录独立视图

前端无需修改底层数据库结构，纯前端实现联机/离线同构的公侯名录呈现：

1. **公侯特征判定 (`isLord`)**：
   - 包含 `【本名：...】` 简介标记的人物；
   - 正名以“公子”、“公孙”开头的人物；
   - 战国封君（孟尝君、信陵君、平原君、春申君）；
   - 正名以“公/侯/伯/王/君”结尾且排除先秦诸子哲人（孔子/老子/庄子/韩非子/管子/荀子等）的人物。
2. **公侯名录分类导航胶囊 (`.person-cat-bar`, `.cat-pill`)**：
   - `全部 (2,402)`
   - `諸侯公侯 · 公侯名錄 (420)`
   - `名臣將相與其他 (1,982)`
   用户可一键切换只查看公侯名录或排除公侯查看将相，分类状态支持点击过滤与即时刷新。
3. **名录卡片与检索结果高亮**：
   - 检索结果条目高亮展示 `[本名：姜小白]`；
   - 详情面板头部突出渲染朱红色本名徽章 `.realname-badge`；
   - 人物索引条目标注金色 `.lord-badge` 徽章 `[公侯]`。
4. **脱机快照 100% 同构同步**：
   - 运行 `python app/tools/export_static.py` 同步静态快照；
   - `dist/app.js`、`dist/index.html`、`dist/data.js` 逻辑完全对齐，脱机双击 `dist/index.html` 体验一致。
