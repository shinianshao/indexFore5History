## 一、背景与目标

**核心任务指标：**
1. **本名直接检索（100% 召回）**：所有三国与魏晋以封号、官爵、行辈或谥号立名的实体（如齐献王、吴孝王、蔡武哀王、鲁殇公、城阳哀王、琅邪悼王、清河康王、济南惠王、邓哀王、吴敬王、王子法、王子宣、王子玷、王子纮等），补齐历史确证本名（司马攸、司马晏、司马晃、司马维、司马兆、司马焕、司马遐、司马遂、曹冲、司马裒、司马玷等），使用真实姓名直接检索即可精准秒出对应王公实体。
2. **公侯名录自动归集**：两晋与三国以真实姓名立名的核心宗藩封王（如西晋八王之乱核心宗王司马亮、司马伦、司马冏、司马颖、司马颙、司马乂、司马肜、司马孚、司马幹、司马遹，曹魏诸王曹植、曹彰、曹宇、曹志，孙吴诸王宗室孙亮、孙休、孙皓、孙和、孙奋，蜀汉宗王刘理等），简介统一规范前置 `【本名：XX】`，前端契约识别后 100% 自动归入“公侯名录”并展示金色 `[公侯]` 徽章。
3. **红线严格不改动计数规则**：零裸王号别名（绝不私加裸“齐王”、“梁王”、“赵王”、“楚王”等），防范跨朝代假阳性碰撞；同时精准隔离条目互见与碎片实体别名，杜绝抢占正名导致 0 命中。
4. **历史考据与朝代纠偏**：纠正种子库中历史遗留的朝代错配（如秦献王司马柬、齐武闵王司马冏由“先秦”纠正为“西晋”并清洗误挂的先秦别名），考实多条自动切词遗留的“王子XX/公孙XX”真实历史身份。
