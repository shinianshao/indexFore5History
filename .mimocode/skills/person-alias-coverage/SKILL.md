# 人物别名覆盖（字 / 尊称 / 跨书 / 长名守卫）

## 何时用

- 「称号不全」「某人搜不到」「A 书有 B 书没有」
- 「漢元帝/魏元帝/趙王倫 都被归到一个人」
- 「字仲達 登记了却 0 命中」
- 新书接入后跨书人物漏召（晋书缺诸葛亮类）

## 核心概念（勿混）

| 字段 | 匹配？ | 用途 |
|------|--------|------|
| `aliases` | **是** | 唯一匹配入口（**只写繁体**） |
| `title` | **否** | 仅展示；UI 文案须写「職銜（不參與檢索）」 |
| `summary` 的「字X」 | 否，除非进 aliases | 仅简介 |
| `GENERIC_MANUAL` | 泛称路径 | 多人同号（武帝/元帝/文王…） |
| 裸官名 | **禁止** core | 丞相/騎都尉/破虜將軍… |
| 官+专名 | 可 core | 丞相斯、飛將軍、蕭相國 |

## 铁律（本项目 2026-09 战役钉死）

1. **裸帝号/王号/庙号一律泛称**：武帝/惠帝/元帝/孝武帝/文王/武王/高祖/景帝/宣帝…  
   禁止单人 core（前科：元帝→司马睿 吃掉漢元帝/魏元帝）。
2. **长名优先**：漢元帝、魏元帝、晉元帝、趙王倫、齊王冏 必须是**独立 core**；  
   有长名时短名不得截出（配 `ALIAS_STOP_PRE/POST`）。
3. **跨书同人只扩 `books`，禁止新建 pid**（`p_simayi` 不要 `p_simayi2`）。  
   多表合并用**并集**，禁止「后表覆盖」把 `["hhs","sgz"]` 冲成 `["js"]`。
4. **断代史追述可见**：漢元帝/魏元帝 等长名 `books` 要含后书（晋书会追述），  
   否则后书里子串短名会抢走。三国人物默认 `sgz-only` 应扩 `js`（宣帝纪大量交战）。
5. **繁名必须 `to_trad` 不动点**：司馬嶽（非岳）、慕容俊/儁 前后一致；  
   否则 `check_trad` A/C 闸失败。
6. **表字**：只收**双字** + 尊称白名单；单字须守卫。  
   「字缺×N」的 N 是**该人命中数**，不是表字出现次数（古籍表字极少）。
7. **守卫做不到 100% 正确（2026 用户口径）**：先尽力改善到最后；  
   仍判不准的**不要硬归**——列入**人工判断清单**等用户反馈；  
   连人工也难判的先标 **「未知」**（`resolve_generic` 走 `none`/`guess` 且 UI 标存疑，禁止伪称 era）。  
   **人工清单条目必须带上下文**（2026-09-25 用户拍板：光给统计数字判不了）：  
   归属分布 + tier 构成 + **原文上下文（前后各 14 字）** + **候选人的朝代**。  
   一律用 `pipeline/_gen_review_items.py` 生成，落到 `docs/17-条目-<批次>.md`；  
   模板与四步流程见 `docs/17-待办-人工判断清单.md` §二/§三。**禁止手敲条目**。
8. **补人（类传/附传）的规矩（2026-09-25 建立）**：  
   - 捞人句式：`X字Y` 准；`X，Y人也` 噪声大（`_gen_class_fill.py --zi-only`）。  
   - 落地前必过 `_class_fill_prep.py`（剔噪声 + 避 pid 冲突），再 `_apply_persons_fill.py <计划>`。  
   - **自动抽必出误抽，入库前人工一定要看原文**：官名+名（京兆尹防）、
     动宾（甄豐校文字部）、复姓截尾（觟陽鸿→陽鴻）、亲属限定语（安孫遂）。  
   - **`books` 只给检测到的那一本书**，不扩。体检 `_probe_class_leak.py`：书外漏召
     绝大多数是同名异人（張溫 hhs/sgz、張玄 hhs/js、魏桓 sj）与短语陷阱
     （史漢「何曾」是副词），扩 books 必然引入误挂。唯一既有例外：
     `build_dict.py` 的「sgz-only 一律扩含 js」。  
   - 异体字（鐘/卹/沖/鑒/説/勛）触发 C 闸 → 登记 `check_trad.py` 的
     `TRADNAME_EXCEPTIONS` **第 ③ 类**（以语料写法为正名），不要反过来改语料。
9. **人名准入/排除闸（五书统一，详见 `docs/18`）**：  
   - 拒：`X太`/`X校`/`X等`、州部连称（徐二州）、地名、书名、官职残片、数量词组  
   - 例外白名单：鄭太、向長、蕭望之、費詩、杜詩、孫禮、孟子  
   - 宁缺勿滥；零命中必复核；跨书只扩 `books`

## 补齐配方

### A. 字（优先）
- `summary` 的 `字X` → aliases（繁体）；双字可 core。
- 单字：`SINGLE_CHAR_PRE/POST` 或不用。

### B. 专属尊称（白名单）
曹公/孟德/本初/恭祖/仲穎… 可进；丞相/太尉/騎都尉 **不可**。

### C. 跨书 books
```text
曹操   ["hhs","sgz"]
司马懿 ["sgz","js"]   # 三国→晋书扩 js
诸葛亮 ["sgz","js"]   # 晋书宣帝纪 73 处追述/交战
汉元帝 ["hs","hhs","sgz","js"]  # 长名追述可见
```
合并逻辑：各 `PERSON_BOOKS_*` 表 **并集**。

### D. 长名/子串守卫
```python
ALIAS_STOP_PRE = {
  "元帝": set("漢汉魏晉晋蜀吳吴"),   # 漢元帝 不得截出元帝
  "文王": set("章元景宣成"),
  "武王": set("章文成宣元"),
  "趙王": set("倫冏乂穎颙"),         # 趙王倫
}
ALIAS_STOP_POST = {"趙王": set("倫冏乂…"), "有若": set("此自公富")}
```
更稳：直接收长名 core（趙王倫），长度降序自然优先。

### E. 泛称登记
- `GENERIC_MANUAL` 多候选；**至少一人 aliases 声明该串**（否则 build_dict 报「手工泛称未登记」）。
- `GENERIC_DEFAULT` 按书意图写；default 须在候选内。

### F. 单字泛称与名臣/名将/上古三家分立（张汤 vs 商汤 vs 陈汤）
- **分书收束铁律**：后世断代史绝不可单字指前朝名臣。`GENERIC_BOOK_CANDIDATES["湯"]` 将后三书强制收束为上古商汤 `["p_tang"]`，张汤与陈汤在后三书单字 100% 清零。
- **非人名全量硬排除**：汤药/汤液/汤熨/火齐汤/和齐汤/苦参汤/汤池/金城汤池/沸汤/赴汤蹈火/汤沐邑/汤官/汤谷等，必须通过字符级三道防线（`SINGLE_CHAR_STOP`、`SINGLE_CHAR_PRE`、`SINGLE_CHAR_STOP2`）与上下文硬规则（`GENERIC_CONTEXT_RULES` 目标为 `None`）双重绞杀。
- **规则作用域陷阱**：`scope == "window"` 会切除目标词本身，若匹配 key 包含被匹配字（如“苦參湯”），`window` 无法命中，必须使用 `scope == "sent"`；前缀词切忌用单字泛词如 `("pre", "臣")`，必须用专属组合词如 `("sent", "大夫臣湯")`。

## 回归链

```text
build_dict → annotate → annotate_pei → annotate_js_note → annotate_places → check_trad
verify --check
_ui_test / _ui_test_books / _ui_test_places
```

建议断言：
- 长名归对人（漢元帝→刘奭、魏元帝→曹奂、趙王倫→司马伦）
- 裸官职 core=0（含騎都尉）
- 跨书：诸葛亮 js≥50、司马懿 sgz≥18
- 零命中人物 ≤3

## 探针

- `_gen_review_items.py` — **人工判断条目生成器**（带原文上下文，`--list` 挑目标）
- `_probe_book_alias_density.py` / `_probe_alias_gaps.py`
- `_probe_title_mis.py` — 帝号/王号错挂系统扫
- `_probe_report_quality.py` / `_probe_js_zaiki.py`
- `_r2_fill_zi.py` / `_r3_strip_office.py` / `_r3c_fill_bios.py`

## 反模式

1. `title` 当 aliases。  
2. 裸官名/裸帝号进单人 core。  
3. 同人跨书建新 pid。  
4. PERSON_BOOKS 后表覆盖丢前书。  
5. 简体写 aliases；繁名非不动点。  
6. 只改词典不重跑 `annotate_pei` / `annotate_js_note`。
