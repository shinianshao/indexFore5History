# 帝号/王号消歧 + 断代史时代窗

## 何时用

- 「晋书元帝/汉元帝/魏元帝都归司马睿了」
- 「武帝在晋书归了刘彻」「景帝归了刘启」
- 「文王/武王进章武王」
- 新断代史要拆「本纪时代 / 相对古人」两组索引

## 〇、正确性上限（2026 用户口径）

古籍守卫**做不到完全正确**。工作顺序固定：

1. **先尽力改善**（长名/守卫/分书候选/择近）到最后；
2. 仍判不准 → **人工判断清单**（交用户勾选反馈，回填 `GENERIC_*` / core）；
3. 连人工也难判 → **先设「未知」**：不写死 default，不伪称 era，宁可 `none`/`guess` 也不张冠李戴。

禁止为了「有依据占比」把真猜包装成 era。

## 一、裸帝号/王号 = 泛称（铁律）

| 禁止 | 正确 |
|------|------|
| 武帝 → 刘彻 core | `GENERIC_MANUAL["武帝"]` 多候选 |
| 元帝 → 司马睿 core | 漢元帝/魏元帝/晉元帝 **长名 core** + 裸元帝泛称 |
| 惠帝 → 刘盈 core | 泛称（刘盈/司马衷） |
| 趙王 → 张耳 core | 泛称 + 长名 趙王倫→司马伦 |

**长名永远优先于短名**：`漢元帝`(3) ≻ `元帝`(2)。  
若长名被 `books` 锁在前书，后书会子串截走——**追述长名要含后书**。

## 二、匹配层守卫

```python
# 前缀：短名不得从专名里截出
ALIAS_STOP_PRE = {
  "元帝": set("漢汉魏晉晋蜀吳吴"),
  "文王": set("章元景宣成"),
  "武王": set("章文成宣元"),
  "趙王": set("倫冏乂穎颙"),
}
# 后缀：短名+单字名 = 长号
ALIAS_STOP_POST = {
  "趙王": set("倫冏乂"),
  "齊王": set("冏倫乂"),
}
```

或直接收长名 core（趙王倫/齊王冏），靠 `compile_alias_pattern` 长度降序。

## 三、泛称归属：追述择近

`resolve_generic` 顺序：

1. owner / related / sentence / paragraph / chapter  
2. era：**同代唯一候选** → 归他  
3. default 若**早于本篇**（追述）：  
   - 有「时代接近」候选（`eraRank >= here-3`）→ 归他（晋景帝=司马师，不落到汉景帝）  
   - 无接近候选 → default 记 `era`（周公/文王追述）  
4. 有同代候选却落更早 default → `guess`，**不得**伪称 era

`ERA_ORDER` 必须覆盖语料全部朝代：

```text
上古…新 東漢 三國 西晉 東晉 十六國
```

缺「三國」会让 sgz/js 的 era 档**静默失效**（踩过）。

## 四、断代史两组索引（BOOK_ERA）

| 书 | 本书记载时代 | 邻书重叠（有意） |
|----|--------------|------------------|
| 史記 | 通史不拆 | — |
| 漢書 | 秦末～新 | 新↔后汉（王莽） |
| 後漢書 | 新～東漢 | 東漢↔三国（汉末） |
| 三國志 | 東漢～三國 | 三國↔晋书 |
| 晉書 | 三國～十六國 | 自司马懿起，三國算本纪时代 |

实现：
- person.`eraRank` = `era_index(dynasty)`  
- book.`eraRange` = `[lo, hi]`  
- 单选断代史：索引拆「本书记载时代 / 相对于本书的古人」，**两组各自排序**  
- **本书篇主强制**归本纪时代（朝代字段偶有偏差）

## 五、诊断清单

1. 表面计数 vs 归属：`_probe_title_mis.py`  
2. 长名是否在词典、`books` 是否含本书  
3. 裸名是否误入单人 core  
4. `ERA_ORDER` 是否缺朝代  
5. default 是否越书（吕后本纪趙王≠张耳）

## 六、回归断言样例

- 漢元帝→刘奭、魏元帝→曹奂、晉元帝→司马睿  
- 晋书：惠帝→司马衷、景帝→司马师（非刘启）  
- 趙王@吕后本纪 不归张耳  
- 周文王 eraRank < 晋书 eraRange.lo ≤ 司马懿 eraRank  
- 泛称有依据：sj≥75% hs≥70% hhs≥45% sgz≥35% **js≥60%**

## 反模式

1. 裸帝号进单人 core。  
2. 长名 books 锁前书，后书子串抢走。  
3. 追述一律 guess 或一律 era（要「择近」）。  
4. `ERA_ORDER` 不更新就接新朝代书。  
5. 两组索引混排不拆，或拆了仍共用一个排序键。
